Partidas guardadas en ranuras ("slot1", "autosave"...), como el Save Game de Unreal. Se guardan los objetos con el componente Saveable, los objetos creados y destruidos durante el juego, los valores sueltos y las variables de los diálogos. El archivo (.crsave, JSON versionado, comprimido si se pide) se escribe en un hilo aparte: el juego no se para.

Componente Saveable

  • Id de guardado: vacío = el UUID del objeto. Ponlo a mano si el objeto se puede borrar y volver a crear en el editor y quieres que las partidas viejas lo sigan encontrando.
  • Transform, Activo, Física (velocidades) y Script (sus propiedades y lo que devuelva OnSave(); al cargar se llama a OnLoad(datos)).
  • Componentes: los que se guardan enteros, por nombre ("Light, AudioSource") o * para todos.

Guardar y cargar

Save::save("slot1", "Antes del jefe");   // etiqueta opcional
Save::load("slot1");                      // si es de otra escena, la abre primero
Save::setValue("oro", 120);
int oro = Save::getValue("oro", 0);
Save::setAutosave(120.0f, "autosave");    // cada 2 minutos

Save.list() da cada ranura con su escena, fecha, tiempo jugado y tamaño (para un menú de cargar partida); Save.onLoaded(funcion) avisa al terminar de cargar.

Dónde se guardan

  • En el editor: Library/Saves del proyecto. Ventana > Partidas guardadas las lista, guarda en Play y las carga o borra.
  • En el juego exportado: %APPDATA%/<juego>/saves (en Windows).
Con Steam (Configuraciones de compilación), Steam.cloudWrite sube una partida a Steam Cloud.
