Los scripts de Cramion se escriben en C++, como los MonoBehaviour de Unity: una clase con start(), update()... y sus propiedades en el Inspector. No hay que instalar nada: el editor trae su compilador (clang) y el IntelliSense (clangd). Corren aislados en otro proceso: si un script falla, el motor sigue y te dice el archivo y la línea.

Crear el script

  1. Proyecto > Añadir > Script C++ (o el botón Nuevo script C++ del componente). Escribe el nombre: es el de la clase.
  2. Se crean Hola.h (la clase y sus propiedades) y Hola.cpp (el código) y se abren en el editor.
  3. Arrastra el .cpp o el .h a un objeto de la escena: se le pone el componente C++ Script.
  4. Guarda (Ctrl+S): se compila solo. Dale a Play.

Assets/Scripts/Hola.h

#pragma once
#include <cramion/Script.h>
using namespace cramion;

class Hola : public Script {
public:
    Property<std::string> mensaje{this, "mensaje", "¡Hola, Cramion!"};
    Property<float> velocidad{this, "velocidad", 90.0f, Range(0, 360)};

    void start() override;
    void update(float dt) override;
};

Assets/Scripts/Hola.cpp

#include "Hola.h"

void Hola::start() {
    Debug::log(mensaje.get() + " desde " + entity().name());
}

void Hola::update(float dt) {
    entity().rotate(Vec3{0.0f, velocidad * dt, 0.0f});
}

CRAMION_SCRIPT(Hola)   // registra la clase (obligatorio)
Importante: cada clase de script termina con CRAMION_SCRIPT(Clase) en su .cpp. Sin eso el componente no la encuentra.

El editor de código e IntelliSense

Doble clic en un .cpp o .h lo abre en el editor integrado (IntelliSense de clangd):

  • Toda la API del motor, primero lo del motor (icono naranja): entity()., Scene::, Audio::, Mathf::... con el nombre de cada parámetro y su descripción.
  • Errores y avisos en vivo (subrayados), la firma al abrir (, información al pasar el ratón e ir a la definición (F12 / Ctrl+clic).
  • Cierra solos ( [ { " ', Formatear (Mayús+Alt+F), Abrir cabecera (Alt+O), Compilar (F7) y la Consola C++.

Todo lo que hay: Entity, Scene, Input, Mathf, Vec3 y Quat y el resto de la API de C++. Más detalles en Scripts en C++.

¿Y Lua?

Lua está obsoleto: sigue funcionando para los proyectos que ya lo usan, pero lo nuevo se hace en C++. Su referencia está en Referencia de Lua (obsoleta). Un script de C++ puede llamar a código Lua que quede con Lua::call("MiTabla.funcion", {...}) mientras lo pasas.
