Los scripts viven en la carpeta Assets del proyecto (por convención, Assets/Scripts/). Desde el editor, crea uno con el menú de assets: se genera con los métodos habituales. Después añade el componente Script a una entidad y elige el archivo.

Assets/Scripts/Hola.lua

local Hola = {
    properties = {
        mensaje = "¡Hola, Cramion!",
    }
}

function Hola:Start()
    Debug.log(self.mensaje, "desde", self.entity.name)
end

function Hola:Update(dt)
end

return Hola   -- obligatorio: el script debe devolver su tabla
Importante: el archivo tiene que terminar con return <tabla>. Si no, la consola mostrará "el script debe terminar con 'return <su tabla>'".

El editor de scripts e IntelliSense

Doble clic en un .lua lo abre en el editor integrado. Mientras escribes (o con Ctrl+Espacio) sale el autocompletado, con la firma y la descripción de cada función:

  • Toda la API del motor: se la pide al propio motor al abrir el editor, así que sale todo lo que existe (Input, XR, Screen, Graphics, Network...).
  • Sabe qué es cada cosa: self.entity, other o Scene.find(...) son entidades; .position o Vec3(...) un Vec3; Quat.euler(...) un Quat; Physics.raycast(...) un choque con entity, point... Y lo sigue por tus variables: tras local p = self.entity.position, p. ofrece x, y, z y p: normalized, length...
  • Dentro de los textos, lo de tu proyecto: componentes (addComponent(") y sus campos (getField("Light", "), acciones y contextos de Input Actions, teclas, tags, objetos de la escena (Scene.find("), escenas, prefabs, sonidos, materiales y las manos y botones de VR.
  • Tus variables, funciones y propiedades, y los métodos que llama el motor tras function MiScript:.
  • Firma: dentro de los paréntesis de una llamada se ve encima del cursor, con el argumento que estás escribiendo resaltado.
