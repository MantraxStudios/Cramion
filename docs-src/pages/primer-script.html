Los scripts viven en la carpeta Assets del proyecto (por convención, Assets/Scripts/). Desde el editor, crea uno con el menú de assets: se genera con los métodos habituales. Después añade el componente Script a una entidad y elige el archivo.

Assets/Scripts/Hola.lua

local Hola = {
    properties = {
        mensaje = "¡Hola, Cramion!",
    }
}

function Hola:Start()
    Debug.log(self.mensaje, "desde", self.entity.name)
end

function Hola:Update(dt)
end

return Hola   -- obligatorio: el script debe devolver su tabla
Importante: el archivo tiene que terminar con return <tabla>. Si no, la consola mostrará "el script debe terminar con 'return <su tabla>'".
