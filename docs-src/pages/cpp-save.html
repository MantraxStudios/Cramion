Partidas guardadas: ranuras, valores sueltos y autoguardado.

Save

Value clearValues(...)borra todos
Value delete_(texto)borra una ranura Devuelve: booleano
Value deleteValue(texto)lo borra
Value exists(texto)existe? Devuelve: booleano
Value folder(...)carpeta de las partidas Devuelve: texto
Value getValue(texto, valor)lee un valor suelto Devuelve: valor
Value hasValue(texto)existe? Devuelve: booleano
Value info(texto)datos de una ranura (o nil) Devuelve: objeto o nil
Value isWriting(...)esta escribiendo en segundo plano? Devuelve: booleano
Value list(...){slot, label, scene, date, playtime, size} de cada ranura Devuelve: lista de objetos
Value load(texto)carga una partida (cambia de escena si hace falta) Devuelve: booleano
Value onLoaded(callback)end) despues de cargar una partida
Value playtime(...)segundos jugados Devuelve: numero
Value remove(texto)borra una ranura (lo mismo que delete) Devuelve: booleano
Value save(texto, texto2)guarda la partida (objetos Saveable, valores, dialogos) Devuelve: booleano
Value setAutosave(valor, texto)autoguardado cada N segundos (0 = no)
Value setCompression(activar)partidas comprimidas
Value setValue(texto, valor)valor suelto (va en cada partida)
