Líquidos por partículas: emisores, densidad y tipos.

Fluid

Value clear(...)borra todo el liquido
Value count(texto)particulas (todas o de un tipo) Devuelve: numero
Value density(pos, radio)0 = seco, ~1 = lleno Devuelve: numero
Value isActive(...)hay liquidos en la escena? Devuelve: bool
Value isInside(pos)hay liquido ahi? Devuelve: bool
Value restart(entidad)vuelve a llenar una caja/esfera
Value setType(entidad, texto)cambia el liquido del emisor
Value spawn(pos, cantidad, texto, vel, radio, vida)crea liquido (bola de particulas)
Value start(entidad)el emisor empieza
Value stats(...){particles, capacity, emitters...} Devuelve: objeto
Value stop(entidad)el emisor para
Value surfaceHeight(x, z)nil o la altura de la superficie Devuelve: numero o nil
Value types(...)lista de tipos Devuelve: lista de texto
Value velocity(pos, radio)velocidad media del liquido (Vec3) Devuelve: Vec3
