Líquidos por partículas: emisores, densidad y tipos.

Fluid

Value clear(...)borra todo el liquido
Value count(texto)particulas (todas o de un tipo)
Value density(pos, radio)0 = seco, ~1 = lleno
Value isActive(...)hay liquidos en la escena?
Value isInside(pos)hay liquido ahi?
Value restart(entidad)vuelve a llenar una caja/esfera
Value setType(entidad, texto)cambia el liquido del emisor
Value spawn(pos, cantidad, texto, vel, radio, vida)crea liquido (bola de particulas)
Value start(entidad)el emisor empieza
Value stats(...){particles, capacity, emitters...}
Value stop(entidad)el emisor para
Value surfaceHeight(x, z)nil o la altura de la superficie
Value types(...)lista de tipos
Value velocity(pos, radio)velocidad media del liquido (Vec3)
