Cargar escenas y objetos de un .datapack en marcha.

DataPack

Value info(texto){name, version, scenes, objects, files} sin montar nada (o nil)
Value instantiate(texto, texto2, posicion, rotacion)monta el paquete y crea un objeto (prefab) suyo; devuelve la Entity o nil
Value isLoaded(texto)esta montado?
Value list(...)nombres de los paquetes montados
Value load(texto)monta un .datapack (junto al juego, en DataPacks/ o ruta); devuelve {name, scenes, objects, files} o nil
Value loadScene(texto, texto2)monta el paquete y carga su escena (la primera si no se dice cual); true/false
Value unload(texto)desmonta el paquete (borra lo que extrajo)
