• Si guardas un .lua durante el modo Play, se vuelve a leer: las instancias conservan sus datos (self.*) y usan las funciones nuevas.
  • Los errores se muestran en la consola del editor con el archivo y la línea; un script con errores no detiene al resto.
  • La consola del editor ejecuta Lua suelto, por ejemplo Scene.find("Jugador").position = Vec3(0, 5, 0).
  • Por seguridad, los scripts no pueden usar dofile, loadfile, io ni os.execute/os.remove. Para guardar datos usa Prefs.
