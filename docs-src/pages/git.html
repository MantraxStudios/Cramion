Control de versiones con Git dentro del editor: ver los cambios, preparar, hacer commit, push y pull, ramas e historial. Usa el git instalado en el sistema (git-scm.com); Git LFS es opcional para imágenes, modelos y audio.

Empezar

Ventana > Control de versiones (Git). Si el proyecto no está en un repositorio, Inicializar repositorio crea uno con un .gitignore pensado para Cramion (Library/, Builds/, logs...) y un .gitattributes que guarda los binarios grandes con Git LFS (PNG, JPG, HDR, FBX, GLB, WAV, OGG, .crpack...) y las escenas y scripts con saltos de línea normales.

Cambios y commit

  • La lista de la izquierda tiene los archivos cambiados (verde nuevo, amarillo modificado, rojo borrado). La casilla los prepara (entran en el commit); Preparar todo / Quitar todo.
  • Clic en un archivo: sus diferencias a la derecha. Clic derecho: Descartar los cambios.
  • Escribe el mensaje y Commit.
  • Pull (solo avance rápido) y Push (a origin, con la rama). Los comandos largos corren en segundo plano; su salida está en la pestaña Salida.

Ramas e historial

El desplegable de arriba cambia de rama; Crear rama hace una nueva y se pasa a ella. La pestaña Historial tiene los últimos 60 commits.

Guarda la escena antes de cambiar de rama: Git cambia los archivos en el disco y el editor vuelve a leer el proyecto.
