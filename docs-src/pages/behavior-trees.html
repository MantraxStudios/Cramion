Los Behavior Trees (árboles de comportamiento) son la IA de Unreal: una raíz, nodos compuestos que deciden el orden, tareas en las hojas, decoradores (condiciones) y servicios (sensores) sobre una pizarra (Blackboard) de variables con tipo. Un árbol es un asset .crbt; un objeto lo usa con el componente Behavior Tree y corre en Play y en el juego exportado.

Crear

  • Proyecto > Crear > Behavior Tree (IA): Vacío o Guardia de ejemplo (ve al "Player", lo persigue y ataca; si lo pierde va al último sitio donde lo vio; si no, patrulla).
  • Doble clic en el .crbt abre el editor; Asignar a la selección pone el componente.
  • El árbol se dibuja de arriba abajo. Arrastrar desde la parte de abajo de un nodo crea un hijo (o soltar en el vacío abre el buscador). Los hijos de la izquierda tienen prioridad: al moverlos se reordenan solos. Ordenar coloca el árbol.

Nodos

TipoNodos
CompuestosSelector (el primer hijo que salga bien), Sequence (todos en orden hasta que uno falle), Parallel (todos a la vez), Random Selector
TareasMove To (NavMesh), Wait, Play Animation, Set Animator Param, Rotate To Face, Set Blackboard, Find Random Point, Run Script (Lua o C++), Send Message, Log
DecoradoresBlackboard (comparar una clave), Script Condition, Is At Location, Cooldown, Loop, Time Limit, Inverter, Force Success, Force Failure
ServiciosFind Nearest With Tag, Distance To, Sight (cono de visión con rayo de línea de vista), Hearing (ruidos y cercanía), Run Script

Los decoradores de condición pueden abortar (observer aborts): Self corta su rama si deja de cumplirse; Lower Priority corta las ramas de la derecha si empieza a cumplirse (el guardia deja de patrullar al ver al jugador). Los servicios corren cada N segundos mientras su rama está activa y escriben en la pizarra.

Depuración en vivo

En Play, el objeto seleccionado que usa el árbol se ve en el editor: la rama activa brilla en azul, cada nodo muestra su último resultado (verde bien, rojo mal, naranja abortado), la pizarra enseña sus valores (y se pueden cambiar para probar) y abajo está el historial de abortos y fallos.

Desde los scripts

local bt = self.entity:getBehaviorTree()
bt:set("objetivo", Scene.find("Player"))
if bt:get("alerta") then bt:restart() end

-- Tarea "Run Script" con funcion "Atacar"
BehaviorTree.registerTask("Atacar", function(self, bt, primera)
    if primera then self.entity:playSpriteAnimation("Golpe") end
    return "success"   -- "running", "success" o "failure"
end)

-- Un ruido que oye el servicio Hearing
BehaviorTree.reportNoise(self.entity.position, 15, self.entity)

Los scripts de C++ reciben las tareas Run Script y Send Message como mensajes (on("Atacar", ...)).
