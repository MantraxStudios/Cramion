Linux (x64): ya hay servidor dedicado nativo (CramionServer) y la capa de plataforma del motor (ventana X11/XWayland, teclado, ratón con captura y superficie de Vulkan Xlib). El reproductor del juego con ventana todavía es solo de Windows: su pantalla de carga, su interfaz y su arranque usan Win32 y GDI+.

Compilar en Linux

sudo apt install clang ninja-build cmake libx11-dev libvulkan-dev
cmake --preset linux-release
cmake --build --preset linux-release
./build-linux/CramionServer --project ~/MiJuego --port 7777

El preset linux-release compila el motor (Core, el render y la ventana Xlib) y CramionServer: el juego sin ventana ni GPU que simula la escena (física, navegación, multitudes, scripts) y abre la partida en red. Sirve tanto para una carpeta de proyecto como para el Game/ de un juego exportado (descomprime su .crpack).
