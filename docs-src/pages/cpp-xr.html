Realidad virtual: casco, mandos, botones y vibración.

XR

Value getAimRay(texto)origen, direccion del puntero (para Physics.raycast)
Value getButton(texto, texto2)boton mantenido: trigger, grip, thumbstick, primary (a/x), secondary (b/y), menu
Value getButtonDown(texto, texto2)boton pulsado este frame
Value getButtonUp(texto, texto2)boton soltado este frame
Value getControllerPosition(texto, texto2)Vec3 de la mano (grip) o del puntero (aim), o nil
Value getControllerRotation(texto, texto2)Quat de la mano o del puntero, o nil
Value getGrip(texto)agarre 0..1
Value getHeadLocalPosition(...)Vec3 de la cabeza dentro de la habitacion
Value getHeadPosition(...)Vec3 de la cabeza en el mundo (o nil)
Value getHeadRotation(...)Quat de la cabeza en el mundo (o nil)
Value getOriginPosition(...)Vec3 del rig (XR Origin o la camara) en el mundo
Value getRuntimeName(...)runtime de OpenXR (SteamVR, Oculus...)
Value getSystemName(...)nombre del casco
Value getThumbstick(texto)Vec3(x, y, 0) del stick, -1..1
Value getTrackingOrigin(...)"floor" o "eyes"
Value getTrigger(texto)gatillo 0..1
Value isAvailable(...)hay casco y sesion de VR
Value isControllerActive(texto)el mando esta encendido y se sigue
Value isFocused(...)el juego tiene los mandos (sin el menu del sistema encima)
Value isRunning(...)el casco esta mostrando el juego
Value setTrackingOrigin(texto)floor (de pie) o eyes (sentado); con XR Origin manda el componente
Value vibrate(texto, valor, valor2)vibracion: intensidad 0..1, segundos, hz
