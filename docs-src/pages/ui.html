Los controles de interfaz llaman a métodos de un script. En el Inspector de un UIButton, UISlider, UIToggle o UIInputField elige la entidad destino (vacío = la misma) y escribe el nombre del método.

ControlEventoFirma del método
UIButtonAl hacer clicfunction X:OnJugar(boton)
UISliderAl cambiarfunction X:OnVolumen(valor)
UIToggleAl cambiarfunction X:OnCasilla(activa)
UIInputFieldAl cambiar / al pulsar Enterfunction X:OnEscribe(texto)
