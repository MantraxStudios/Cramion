Diálogos ramificados: empezar, seguir, elegir y avisos.

Dialogue

Value advance(...)lo mismo que next
Value choices(...)lista de {index, text, enabled}
Value choose(valor)elige la opcion 1..n
Value currentLine(...){speaker, text, audio, node, autoAdvance} o nil
Value getVar(texto)lee una variable
Value isActive(...)hay un dialogo en marcha?
Value isWaitingChoice(...)esta esperando que se elija?
Value name(...)dialogo que corre
Value next(...)sigue tras una linea
Value onChoices(callback)end) opciones para elegir
Value onEnd(callback)end) al terminar
Value onEvent(callback)end) nodo Evento
Value onLine(callback)end) cada linea
Value onStart(callback)end) al empezar
Value setAutoAudio(activar)reproduce solo el audio de cada linea
Value setVar(texto, valor)variable de los dialogos
Value start(texto)empieza un .crdialog (nombre o ruta)
Value stop(...)lo corta
