Como el Enhanced Input de Unreal: en vez de preguntar por teclas sueltas, el juego define acciones (lo que hace el jugador) y contextos (qué teclas, botones o ejes las activan). Una acción puede tener muchas teclas a la vez (teclado, ratón, mando y joystick táctil), y puedes tener varias configuraciones (a pie, vehículo, vuelo, menú...) y activarlas o desactivarlas desde C++.

Dónde se configura

En Archivo > Entrada del proyecto (acciones y teclas). Todo se guarda al momento en ProjectSettings/InputActions.json y el juego exportado (PC y Android) lo carga solo. En Play los cambios se aplican al instante. La ventana tiene tres pestañas:

  • Acciones (Input Actions): nombre, tipo de valor, descripción, cómo se combinan varias teclas, modificadores y triggers de la acción.
  • Contextos (Mapping Contexts): nombre, prioridad, si está activo al empezar y, por cada acción, su lista de teclas. Cada tecla tiene sus propios modificadores y triggers. El botón ... junto a una tecla (o + tecla) espera a que pulses la tecla o el botón del mando; Escape cancela.
  • Depurar (Play): el estado (none / ongoing / triggered), el valor y el tiempo de cada acción, y los contextos activos.

Un proyecto sin archivo usa la configuración por defecto (se puede editar a partir de ella):

TipoEn C++ (Input::getAction, un Value)Ejemplo

Cada tecla da un valor: un botón da 1 en x; un eje (Gamepad LT, Mouse Wheel) un número en x; un stick (Gamepad Left Stick, Mouse XY, Touch Stick) x e y. Los modificadores lo llevan al eje que toca. Con varias teclas pulsadas a la vez, por defecto se toma el mayor valor en cada sentido (W + S = 0; W + flecha arriba = 1, no 2); la opción Sumar las suma.

Modificadores

Se aplican en orden: primero los de la tecla y luego los de la acción.

NegateCambia el signo de los ejes marcados (X, Y, Z). A en Move = Negate → (−1, 0).
SwizzleReordena los ejes. YXZ: una tecla 1D mueve la Y (W en un Vec2 = adelante). ZYX: a la Z (adelante en un Vec3). XZY: la Y de un stick pasa a Z. También YZX y ZXY.
Dead ZoneIgnora el valor por debajo de Min y reescala hasta Max. Radial usa la magnitud (sticks); si no, cada eje por separado.
ScaleMultiplica cada eje (sensibilidad del ratón o del stick).

Ejemplo: Move (Vec2) = W [Swizzle YXZ], S [Swizzle YXZ, Negate], D, A [Negate], Gamepad Left Stick [Dead Zone].

Triggers

Deciden cuándo se dispara la acción. Sin triggers, está disparada mientras tiene valor (Bool: a partir de 0.5). Umbral es la magnitud mínima para contar como pulsado.

DownCada frame mientras está pulsada.
PressedSolo el frame en que se pulsa.
ReleasedSolo el frame en que se suelta (en curso mientras se mantiene).
HoldTras mantenerla s segundos. Una vez: dispara una vez; si no, cada frame desde entonces.
Hold And ReleaseAl soltar, si se mantuvo al menos s segundos (cargar un arco).
TapAl soltar, si se soltó antes de s segundos; si se mantiene más, se cancela.
PulseCada s segundos mientras se mantiene (disparo automático). Al empezar dispara también al pulsar; Límite 0 = sin límite.
ChordSolo si otra acción está disparada a la vez (Ctrl + C: la acción Copiar con Chord de Modificador).

Cada frame la acción puede lanzar estos eventos (como ETriggerEvent de Unreal):

startedEmpezó (el primer frame con valor o en curso).
ongoingEn curso sin disparar todavía (manteniendo un Hold).
triggeredDisparada.
completedTerminó después de dispararse.
canceledTerminó sin llegar a dispararse (se soltó un Hold antes de tiempo).

Contextos y prioridad

Puede haber varios contextos activos a la vez. Si dos comparten una tecla, el de más prioridad se la queda (si su acción tiene Consumir las teclas, activo por defecto) y el otro no la recibe. A igual prioridad gana el último añadido. Ej.: con Vuelo (prioridad 1) activo, W mueve Fly y no Move; al quitarlo, vuelve a Move.

API de C++

Están en el namespace Input y devuelven un Value (.asBool(), .asNumber(), .asVec3(), .asString(), .isNil()). Ver Input.

Input::getAction(accion)Valor según su tipo: bool, número o Vec3. Nil (y un aviso) si no existe.
Input::getActionValue(accion)Siempre un Vec3.
Input::getActionState(accion)"none", "ongoing" o "triggered".
Input::isActionTriggered(accion)Disparada este frame (respeta los triggers: con Pressed, solo el frame de la pulsación).
Input::isActionOngoing(accion)En curso sin disparar.
Input::wasActionStarted(accion), …Completed, …CanceledEse evento pasó este frame.
Input::getActionElapsed(accion)Segundos desde que empezó (cuánto se lleva manteniendo).
Input::bindAction(accion, evento, funcion)Llama a funcion (una lambda [this](const Values& a): a[0] es el valor y a[1] los segundos) cuando pasa el evento ("started", "ongoing", "triggered", "completed", "canceled"). Devuelve un id. Se quitan solas al parar el juego o cambiar de escena.
Input::unbindAction(id)Quita un bindAction.
Input::getActions()Lista con los nombres de las acciones.
Input::addMappingContext(nombre, prioridad)Activa un contexto (con su prioridad o la que se pase; la prioridad es opcional). false si no existe.
Input::removeMappingContext(nombre)Lo desactiva.
Input::hasMappingContext(nombre)Si está activo.
Input::clearMappingContexts()Desactiva todos (nada responde hasta añadir uno).
Input::getMappingContexts()Los activos, de más a menos prioridad.
Input::getBindings(accion)Lista de objetos {context, key} con sus teclas en todos los contextos.
Input::rebind(contexto, accion, n, tecla)Cambia la tecla número n (1 = la primera) de esa acción en ese contexto. false si no existe, la tecla no es válida o la tecla no es cambiable por el jugador.
Input::saveBindings()Guarda las teclas cambiadas (con los Prefs del juego): se cargan solas en la próxima partida.
Input::resetBindings()Vuelve a las teclas del proyecto y borra las guardadas.
Input::anyKeyPressed()La tecla o botón pulsado este frame ("W", "Mouse Left", "Gamepad A") o nil. Para menús de "pulsa una tecla".
Input::getAxis(accion)También vale con el nombre de una acción: su x.

Ejemplos

Personaje con Move (Vec2), Look (Vec2), Jump (Bool) y Zoom (float):

#include <cramion/Script.h>

using namespace cramion;

class Jugador : public Script {
public:
    Property<float> velocidad{this, "velocidad", 5.0f};
    Property<float> sensibilidad{this, "sensibilidad", 2.0f};

    void awake() override {
        // Evento: una vez al pulsar (vale cualquier tecla de Jump: Space, mando A, boton tactil)
        Input::bindAction("Jump", "started", [this](const Values&) {
            entity().addImpulse(Vec3{0, 5, 0});
        });
    }

    void update(float dt) override {
        const Vec3 mover = Input::getAction("Move").asVec3();     // x derecha, y adelante
        const Vec3 mirar = Input::getAction("Look").asVec3();     // x girar, y arriba
        const float zoom = Input::getAction("Zoom").asFloat();    // numero
        float rapidez = velocidad;
        if (Input::getAction("Sprint").asBool()) rapidez *= 2.0f; // Bool

        yaw_ -= mirar.x * sensibilidad;
        entity().setRotation(Vec3{0, yaw_, 0});
        const Vec3 dir = entity().right() * mover.x + entity().forward() * mover.y;
        entity().translate(dir * (rapidez * dt));
    }

private:
    float yaw_ = 0.0f;
};

CRAMION_SCRIPT(Jugador)

Cambiar de configuración: subir a un vehículo o ponerse a volar (Vec3):

void Jugador::update(float dt) {
    if (Input::isActionTriggered("Interact").asBool()) {       // trigger Pressed: una vez
        if (Input::hasMappingContext("Vuelo").asBool()) {
            Input::removeMappingContext("Vuelo");
        } else {
            Input::addMappingContext("Vuelo");                 // prioridad 1: se queda W/A/S/D/E/Q
        }
    }
    if (Input::hasMappingContext("Vuelo").asBool()) {
        const Vec3 v = Input::getAction("Fly").asVec3();       // x derecha, y arriba, z adelante
        entity().translate(v * (8.0f * dt));
    }
}

Menú de opciones: "pulsa una tecla" para cambiar el salto y guardarlo:

void Opciones::update(float dt) {
    if (esperando_) {
        const Value tecla = Input::anyKeyPressed();
        if (tecla.asString() == "Escape") {
            esperando_ = false;
        } else if (!tecla.isNil()) {
            if (Input::rebind("Default", "Jump", 1, tecla).asBool()) {
                Input::saveBindings();
            }
            esperando_ = false;
        }
    }
}

void Opciones::mostrarTeclas() {
    for (const Value& b : Input::getBindings("Jump").items()) {
        Debug::log(b["context"].asString() + ": " + b["key"].asString());
    }
}
