Multijugador: crear y unirse, mensajes, objetos de red.

Network

Value SERVER()Network.SERVER: id del servidor (1)
Value connect(texto, valor)se une a una partida (llega onConnected u onDisconnected)
Value destroy(entity)lo borra en todos (solo el servidor)
Value disconnect(...)sale de la partida (o la cierra si eres el servidor)
Value find(netId)entidad por su id de red
Value host(valor, valor2)crea la partida (eres el servidor y juegas); devuelve ok, error
Value isActive(...)hay sesion de red
Value isClient(...)eres un cliente?
Value isConnected(...)en partida (servidor abierto o cliente dentro)
Value isConnecting(...)cliente esperando respuesta
Value isServer(...)eres el servidor?
Value loadScene(texto)todos cargan la escena (solo el servidor)
Value myId(...)tu id de jugador (el servidor es 1)
Value objects(...)todas las entidades de red
Value off(texto)deja de recibirlo
Value on(texto, callback)end) recibe un mensaje
Value onConnected(callback)end) cliente: ya estas dentro
Value onDisconnected(callback)end) fuera de la partida
Value onPlayerJoined(callback)end) entra un jugador
Value onPlayerLeft(callback)end) sale un jugador
Value ping(id)ida y vuelta en ms
Value playerCount(...)cuantos jugadores
Value players(...)lista de ids de jugadores
Value send(texto, datos, destino)mensaje (destino: nil = todos, "server" o un id)
Value spawn(texto, posicion, dueno)crea un objeto de red en todos (solo el servidor)
Value stats(...){sent, received, objects}
