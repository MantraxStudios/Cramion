Multijugador: crear y unirse, mensajes, objetos de red.

Network

Value SERVER()Network.SERVER: id del servidor (1) (numero)
Value connect(texto, valor)se une a una partida (llega onConnected u onDisconnected) Devuelve: lista {ok, error}
Value dedicated()Network.dedicated: true en un servidor dedicado (lo pone CramionServer) (bool)
void setDedicated(const Value& v)Cambia Network.dedicated
Value destroy(entity)lo borra en todos (solo el servidor)
Value disconnect(...)sale de la partida (o la cierra si eres el servidor)
Value find(netId)entidad por su id de red Devuelve: Entity
Value host(valor, valor2)crea la partida (eres el servidor y juegas); devuelve ok, error Devuelve: lista {ok, error}
Value isActive(...)hay sesion de red Devuelve: bool
Value isClient(...)eres un cliente? Devuelve: bool
Value isConnected(...)en partida (servidor abierto o cliente dentro) Devuelve: bool
Value isConnecting(...)cliente esperando respuesta Devuelve: bool
Value isDedicated(...)true en CramionServer (servidor dedicado sin ventana) Devuelve: bool
Value isServer(...)eres el servidor? Devuelve: bool
Value lagCompensatedRaycast(origen, direccion, distancia, jugador, radio, altura)servidor: disparo de un jugador contra donde el veia a los demas (compensacion de lag) Devuelve: {netId, point, distance} o nil
Value loadScene(texto)todos cargan la escena (solo el servidor)
Value myId(...)tu id de jugador (el servidor es 1) Devuelve: numero
Value objects(...)todas las entidades de red Devuelve: lista de Entity
Value off(texto)deja de recibirlo
Value on(texto, callback)end) recibe un mensaje
Value onConnected(callback)end) cliente: ya estas dentro
Value onDisconnected(callback)end) fuera de la partida
Value onPlayerJoined(callback)end) entra un jugador
Value onPlayerLeft(callback)end) sale un jugador
Value ping(id)ida y vuelta en ms Devuelve: numero
Value playerCount(...)cuantos jugadores Devuelve: numero
Value players(...)lista de ids de jugadores Devuelve: lista de numeros
Value positionAt(netId, segundos)donde estaba un objeto de red hace unos segundos (historia de 1,5 s) Devuelve: Vec3
Value send(texto, datos, destino)mensaje (destino: nil = todos, "server" o un id) Devuelve: bool
Value simulate(tabla)simula una red mala (ms de retraso, variacion y % de perdida; 0 = normal)
Value spawn(texto, posicion, dueno, giro)crea un objeto de red en todos (solo el servidor) Devuelve: Entity
Value stats(...){sent, received, objects, sendRate, receiveRate, bytesSent, bytesReceived, ping, packetLoss} Devuelve: objeto
