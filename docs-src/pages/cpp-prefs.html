Datos guardados entre partidas (como PlayerPrefs).

Prefs

Value deleteAll(...)borra todo
Value deleteKey(texto)la borra
Value getFloat(texto, valor)lee un numero
Value getInt(texto, valor)lee un entero (o el valor por defecto)
Value getString(texto, texto2)lee un texto
Value hasKey(texto)existe?
Value setFloat(texto, valor)guarda un numero
Value setInt(texto, valor)guarda un entero
Value setString(texto, texto2)guarda un texto
