Llamar a cualquier función o propiedad de la API por su nombre.

Api

Value call(std::string_view fn, Values args = {})Llama a cualquier funcion de la API por su nombre: Api::call("Audio.playOneShot", {"x.wav"}).
Value get(std::string_view path)Lee cualquier propiedad de la API ("Time.timeScale", "Network.isServer").
void set(std::string_view path, const Value& v)Cambia una propiedad de la API: Api::set("Graphics.vsync", false).
void send(std::string_view fn, Values args = {})Como call, sin esperar la respuesta (va en el lote: mas rapido).
