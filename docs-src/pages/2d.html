Herramientas 2D como las de Unity: sprites y hojas de sprites, animación por fotogramas, tilemaps con Rule Tiles, luces 2D y una física 2D propia (en el plano XY, aparte de la física 3D). Todo se dibuja sobre la imagen de la escena (se puede mezclar con 3D) y funciona en el juego exportado y en Android.

Vista 2D

El botón 2D de la barra de la Escena pone la cámara del editor ortográfica mirando el plano XY: rueda = zoom hacia el ratón, botón central o derecho = desplazar. Un clic elige sprites y tilemaps. Para el juego, la Cámara tiene Ortográfica y Tamaño (la mitad de lo que se ve en vertical).

Sprites

  • Sprite Renderer: la imagen (arrástrala desde el Proyecto), el corte de la hoja, tinte, opacidad, volteo, Capa de orden y Orden en la capa, Iluminado (le afectan las Luces 2D), corte alfa (pixel art) y modo Mosaico (repite el sprite hasta llenar un tamaño).
  • Sprite Editor (Ventana > 2D): suelta una imagen. Single = la imagen entera; Multiple = hoja de sprites, cortada por rejilla (tamaño de celda, margen y separación), por filas y columnas o automático (islas de píxeles opacos). Píxeles por unidad, pivote y filtro Point para pixel art. Los ajustes van en <imagen>.crsprite.
  • Sprite Animator: clips de fotogramas ("0-5, 8") a N fps con bucle. En los scripts: entity().playSpriteAnimation("Correr").
  • Luz 2D: puntual (radio y caída) o global (la luz ambiente de los sprites iluminados).
  • Ventana > 2D > Capas de orden: las Sorting Layers del proyecto, de atrás adelante.

Tilemaps

  • Proyecto > Crear > 2D > Tileset: una imagen cortada en celdas. En su editor se marcan las celdas sin colisión (decoración) y se crean Rule Tiles: tiles que eligen su dibujo según sus 8 vecinos (+ Terreno 3x3 crea las reglas de un terreno con bordes y esquinas a partir de 3×3 celdas).
  • Paleta de tiles (botón Paleta de la vista 2D): con un objeto con Tilemap seleccionado, pinta con Pincel, Rectángulo, Relleno, Borrar (o Mayús) y Gotero, por capas (fondo, suelo, detalles...). Crear Tilemap hace uno con su collider.
  • El Tilemap se guarda por trozos de 16×16 celdas y solo se redibuja lo que cambia.

Física 2D

Rigidbody 2D (dinámico, cinemático o estático; gravedad, rozamiento, congelar giro o ejes), Box, Circle y Polygon Collider 2D, Tilemap Collider 2D (las celdas sólidas unidas en rectángulos, sin costuras al deslizar) y Composite Collider 2D. Los colliders tienen fricción, rebote, trigger y Un sentido (plataformas que se atraviesan saltando desde abajo). 

class Jugador : public Script {
public:
    void start() override {
        // Los eventos 2D llegan como mensajes con {other, point, normal, relativeVelocity}.
        on("OnCollisionEnter2D", [](const Value& contacto) {
            const Entity otro = contacto["other"].asEntity();
            if (otro.tag() == "Moneda") otro.destroy();
        });
    }

    void update(float dt) override {
        Vec3 v = entity().velocity2D().asVec3();
        v.x = Input::axis("Horizontal") * 6.0f;
        if (Input::keyDown("Space") && !Physics2D::raycast(entity().position(), Vec3{0, -1, 0}, 0.6f).isNil()) {
            v.y = 12.0f;
        }
        entity().setVelocity2D(v);
        entity().setFlipX(v.x < 0.0f);
    }
};
CRAMION_SCRIPT(Jugador)

También OnCollisionStay2D/Exit2D, OnTriggerEnter2D/Stay2D/Exit2D (con on(...)), addForce2D, Physics2D::overlapCircle/overlapBox/overlapPoint y en los Tilemap setTile, getTile, worldToCell y cellToWorld.
