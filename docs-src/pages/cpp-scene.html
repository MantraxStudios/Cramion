Cargar escenas sin parar el juego (pantallas de carga propias)

Como SceneManager.LoadSceneAsync de Unity: Scene::loadAsync("Nivel2") lee el .crscene en otro hilo, lee sus modelos (mallas, texturas, LODs) en los hilos del motor y crea sus objetos ocultos por tandas (scene.LoadBudgetMs, 4 ms por frame). Mientras tanto la escena actual sigue jugando y dibujándose y tu pantalla de carga se anima sin tirones: el motor no dibuja ninguna barra. progress() va de 0 a 0.9 mientras carga, se queda en 0.9 si pusiste allowActivation(false) y pasa a 1 al activarse.

  • Single (por defecto): al activarse, en un solo frame, se paran los sistemas de la escena vieja (física, audio, terreno, navegación...), se destruyen sus objetos (con onDestroy) salvo los dontDestroyOnLoad(), se activan los nuevos y los sistemas arrancan con ellos. Los scripts no se reinician: los objetos persistentes siguen con su estado.
  • Additive: la escena se suma a la actual; Scene::unloadAsync("Nombre") la quita.

Mensajes (on("OnSceneActivated", ...)): OnSceneLoadProgress {id, scene, progress} al objeto que pasaste como notify; OnSceneActivated, OnSceneUnloaded y OnSceneLoadFailed {id, scene, mode} a todos los objetos con scripts.

class Portal : public Script {
    AsyncOperation op_;
public:
    void awake() override { on("OnSceneActivated", [this](const Value&) { /* fundido de salida */ }); }
    void entrar() {
        entity().dontDestroyOnLoad();              // esta pantalla sobrevive al cambio
        op_ = Scene::loadAsync("Mazmorra");      // la escena actual sigue animandose
        op_.allowActivation(false);                // esperar al fundido
    }
    void update(float) override {
        if (!op_) return;
        barra.setField("UISlider", "value", op_.progress() / 0.9f);
        if (op_.progress() >= 0.9f && fundidoCompleto()) op_.allowActivation(true);  // cambio en 1 frame
    }
};

Scene::load("Nivel2") sigue como siempre (al terminar el frame se para todo, se carga y se vuelve a empezar), pero ya no dibuja la barra del motor encima: se ve el último frame hasta que la escena nueva está lista. La barra antigua se puede volver a poner en la configuración de compilación (Mostrar progreso de carga del motor, apagado por defecto). Con Scene::load los objetos dontDestroyOnLoad() también pasan a la escena nueva, pero sus scripts empiezan de nuevo.
