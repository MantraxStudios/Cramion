Buscar, crear, instanciar y destruir objetos; cambiar de escena.

Scene

Entity find(std::string_view name)El primer objeto con ese nombre (no valida si no hay).
Entity findWithTag(std::string_view tag)El primer objeto con esa etiqueta.
Entity create(std::string_view name = "Nuevo")Crea un objeto vacio.
std::vector<Vec3> getPositions(const std::vector<Entity>& entities)Las posiciones de muchos objetos en una llamada (rapido).
void setPositions(const std::vector<Entity>& entities, const std::vector<Vec3>& positions)Mueve muchos objetos en una llamada (rapido).
void setTransforms(const std::vector<Entity>& entities, const std::vector<Vec3>& positions, const std::vector<Quat>& rotations = {}, const std::vector<Vec3>& scales = {}, bool local = false)Posicion, giro y escala de muchos objetos en una llamada (va en el lote, sin esperar al motor). La posicion es del mundo (local = true: respecto al padre); el giro (Quat) y la escala, locales. Una lista vacia no se toca: setTransforms(balas, posiciones, giros) no cambia la escala. Si una lista es mas corta que entities, solo se mueven los que tienen todos sus datos.
Value acquire(texto, posicion, rotacion, padre)Saca una copia del pool del prefab (o crea una si esta vacio), la pone donde se pide (rotacion en grados o Quat) y la activa Devuelve: Entity
Value cancelSpawn(id)Cancela un Scene.instantiateAsync (borra lo que ya se habia creado) Devuelve: bool
Value destroy(entity)Lo destruye al final del frame (en la consola fuera de Play, al terminar el comando)
Value destroyDeferred(entity)Lo desactiva ya y lo destruye (con sus hijos) repartido en varios frames (scene.DestroyBudgetMs)
Value findAllWithTag(texto)Lista de objetos con ese tag Devuelve: lista de Entity
Value instantiate(arg, posicion, rotacion)Copia de un objeto (con hijos y componentes) o instancia de un prefab Devuelve: Entity
Value instantiateAsync(texto, posicion, rotacion, padre)Instancia un prefab sin tirones: lee y parsea en otro hilo y crea las entidades por tandas (scene.SpawnBudgetMs por frame) bajo una raiz desactivada que se activa al terminar. Devuelve un id para Scene.spawnProgress / Scene.spawnResult Devuelve: numero
Value load(texto)Cambia de escena al terminar el frame (nombre o ruta del .crscene) Devuelve: bool
Value name(...)Nombre de la escena actual Devuelve: texto
Value origin(...)x, y, z (doble precision) del origen flotante del mundo Devuelve: lista de 3 numeros
Value pool(texto, n)Prepara un pool: deja n copias del prefab creadas y desactivadas (por tandas, con scene.SpawnBudgetMs) para Scene.acquire Devuelve: bool
Value poolCount(texto)Copias libres (creadas y desactivadas) en el pool del prefab Devuelve: numero
Value preloadPrefab(texto)Lee y parsea el prefab en otro hilo y lo guarda en la cache (sin instanciarlo) Devuelve: bool
Value release(entity)Devuelve una copia de Scene.acquire a su pool (la desactiva: onDisable). Si no es de un pool, la destruye como Scene.destroy Devuelve: bool
Value spawnProgress(id)Progreso de Scene.instantiateAsync: 0..1 (1 = lista), -1 si fallo o no existe Devuelve: numero
Value spawnResult(id)La raiz instanciada por Scene.instantiateAsync cuando ya esta (nil si aun no o si fallo); se recoge una vez Devuelve: Entity
Value toAbsolute(posicion)x, y, z absolutos (para guardar posiciones en una partida) Devuelve: lista de 3 numeros
Value toLocal(x, y, z)Vec3 local de una posicion absoluta guardada Devuelve: Vec3
