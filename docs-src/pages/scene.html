Mundos grandes: origen flotante

Los números de las posiciones (float) solo tienen unas 7 cifras: lejos del centro todo tiembla. Cramion lo evita solo: cuando la cámara se aleja más de 2 km del origen, el mundo entero se desplaza (en pasos de 1024 m) para que vuelva a estar cerca, y guarda en doble precisión dónde está de verdad ese origen. Las mallas, la luz, las sombras, la física, los bloques, la navegación y el sonido siguen igual; tú no tienes que hacer nada si lees las posiciones cada frame (self.entity.position).

FunciónQué hace
Scene.origin()x, y, z (doble precisión) del origen actual del mundo.
Scene.toAbsolute(pos)x, y, z reales de una posición: úsalo para guardar posiciones en una partida.
Scene.toLocal(x, y, z)Vec3 local de una posición real guardada (al cargar).
function Script:OnOriginShift(offset)Se llama cuando el mundo se desplaza -offset: resta offset a las posiciones que tengas guardadas en variables (un destino, un punto de aparición).
 
function Script:Start()
    self.destino = Vec3(5000, 0, 200)
end

-- El mundo se desplazo: el destino guardado tambien.
function Script:OnOriginShift(offset)
    self.destino = self.destino - offset
end

-- Guardar y cargar la posicion del jugador sin perder precision
function Script:guardar()
    local x, y, z = Scene.toAbsolute(self.entity.position)
    Prefs.setString("jugador", x .. "," .. y .. "," .. z)
end
