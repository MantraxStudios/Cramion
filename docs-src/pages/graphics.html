Graphics cambia la configuración gráfica desde un script, como el QualitySettings y el Screen de Unity juntos: calidad rápida, escalado y resolución, nitidez, VSync, FPS objetivo, sombras, texturas, trazado de rayos, ventana y el post-procesado de la escena. Todo lo que hay en Ajustes de render y en el componente PostProcessing se puede tocar desde C++; sirve para montar el menú de opciones del juego. 

Graphics::setQuality("Alta");           // Baja, Media, Alta, Ultra (o 0..3)
Graphics::set("vsync", true);           // cualquier opción por su nombre
Graphics::setTextureQuality("high");   // texturas: auto, low, medium, high, ultra, max
Graphics::setTextureFiltering(16);      // anisotrópico: 0 = auto, 1 = apagado, 2, 4, 8, 16
Graphics::set(Value{{"shadow_quality", "ultra"}, {"target_fps", 144}});   // varias a la vez
Graphics::setPost("bloom", false);      // post-procesado de la escena
Graphics::save();                       // el juego lo recuerda la próxima vez

Funciones

FunciónQué hace
Graphics::setQuality(nivel)Calidad rápida: "Baja", "Media", "Alta", "Ultra" (también "low"... o un número 0..3). Ajusta escalado, resolución, nitidez, sombras, sonda de reflexión y trazado de rayos a la vez, igual que los botones del editor.
Graphics::getQuality()La última calidad rápida aplicada (.asString()), o "Personalizada" si luego se cambió algo suelto.
Graphics::qualityLevels()Lista de calidades (para un desplegable; .items()).
Graphics::set(clave, valor)
Graphics::set(Value{{"clave", valor}, ...})		Cambia una o varias opciones. Devuelve true (.asBool()) si se aplicaron; si no, avisa en la Consola por qué (clave que no existe, de solo lectura, valor fuera de la lista).
Graphics::get(clave)El valor actual (.asBool(), .asNumber() o .asString(); vacío si la clave no existe).
Api::get("Graphics.clave") / Api::set("Graphics.clave", valor)Lo mismo por su ruta: Api::get("Graphics.vsync"), Api::set("Graphics.upscaler", "fsr1").
Graphics::getAll()Objeto clave → valor con todo.
Graphics::options()Lista para construir un menú: cada elemento tiene key, value, writable, description y, si es de una lista, choices.
Graphics::setTextureQuality(nivel)
Graphics::textureQuality()
Graphics::textureQualityLevels()		Calidad de las texturas (texture_quality): "auto", "low", "medium", "high", "ultra" o "max". Se aplica a lo que se carga después (ver la nota). textureQuality() devuelve la elegida ("custom" si se dio un tamaño suelto) y textureQualityLevels() la lista para un desplegable.
Graphics::setTextureFiltering(n)
Graphics::textureFiltering()
Graphics::textureFilteringLevels()		Filtrado anisotrópico (texture_filtering): 0 = según el PC, 1 = apagado, 2, 4, 8 o 16; también por nombre ("auto", "off", "16x"). Se aplica al momento a modelos, terreno, vegetación, agua y vóxeles. textureFiltering() devuelve el que está en uso (un número; con auto, el del perfil del PC).
Graphics::setTextureLodBias(sesgo)
Graphics::textureLodBias()		Sesgo de los mipmaps (texture_lod_bias, -1 .. 2): negativo = texturas más nítidas de lejos (y más parpadeo), positivo = más suaves y menos ancho de banda. 0 = normal. Al momento.
Graphics::resolutions()Resoluciones del monitor, de mayor a menor: una lista de objetos con width y height (r["width"].asInt()).
Graphics::save()En el juego exportado guarda la configuración del jugador (incluida la ventana) en %LOCALAPPDATA%/Cramion/Saves/<juego>.graphics.ini. Al volver a abrir el juego se aplica encima de la de ProjectSettings/Graphics.ini. En el editor no guarda nada.

De solo lectura: gpu, hardware_tier, vram_mb, vram_used_mb, ray_tracing_supported, render_width/render_height (resolución interna), screen_width/screen_height (salida) y gpu_ms (milisegundos de GPU por frame), texture_filtering_active (anisotrópico en uso) y texture_filtering_max (el máximo de la GPU). De la vegetación: foliage_trees (árboles en la GPU), foliage_visible (dibujados el último frame), foliage_near (con todo el detalle) y foliage_triangles.

Texturas: texture_quality se aplica a los modelos que se cargan después. En un menú de opciones, vuelve a cargar la escena para verlo: Scene::load(Scene::name()). texture_filtering y texture_lod_bias se ven al momento (el motor rehace los samplers al empezar el frame siguiente, con un parón de unos milisegundos: cámbialos desde un menú, no cada frame).
Presupuesto adaptativo: con adaptive activado el motor puede bajar sombras, efectos o resolución por su cuenta si no llega a los FPS; para que se quede exactamente lo que elige el jugador, desactívalo.
En el editor: lo que cambien los scripts en Play se deshace al parar; la ventana no se toca.

Texturas: calidad, filtrado anisotrópico y mipmaps

Tres opciones controlan cómo se ven las texturas. La calidad (texture_quality) es el lado máximo con el que se suben (memoria de vídeo) y vale para lo que se carga después. El filtrado anisotrópico (texture_filtering) quita el borroso de los suelos y las paredes vistos en ángulo, y el sesgo de los mipmaps (texture_lod_bias) elige entre nitidez y estabilidad de lejos; estas dos se aplican al momento. En el editor están en Ajustes de render > Gráficos > Texturas. 

// Un desplegable por opción, con los valores que da el motor.
for (const Value& nivel : Graphics::textureQualityLevels().items()) Debug::log(nivel.asString());     // auto, low ... max
for (const Value& filtro : Graphics::textureFilteringLevels().items()) Debug::log(filtro.asString()); // auto, off, 2x ... 16x

Graphics::setTextureQuality("ultra");     // 8192 como mucho (al recargar la escena)
Graphics::setTextureFiltering("8x");      // o 8; 0 = según el PC, 1 = apagado
Graphics::setTextureLodBias(-0.25);       // un poco más nítidas de lejos

Debug::log("Calidad " + Graphics::textureQuality().asString() + ", anisotrópico " +
           std::to_string(Graphics::textureFiltering().asInt()) + "x de " +
           std::to_string(Graphics::get("texture_filtering_max").asInt()) + "x posibles");
Graphics::save();                         // el jugador lo recupera al abrir el juego

Todas pasan por Graphics::set: Graphics::set("texture_filtering", 16) es lo mismo que Graphics::setTextureFiltering(16), y valen en Graphics::set(Value{...}) con otras opciones. Un valor que no está en la lista no cambia nada y avisa en la Consola.

Post-procesado: Graphics::setPost

Graphics::getPost y Graphics::setPost leen y cambian el volumen de post-procesado global de la escena (el de mayor prioridad; si la escena no tiene, se crea uno). Las claves son las del componente PostProcessing: exposición, tonemapping, color, bloom, viñeta, lente, rayos de sol, SSAO, GI, reflejos, sombras de contacto, luz volumétrica, LODs, FXAA... Graphics::postKeys() devuelve la lista completa. 

Graphics::setPost("bloom", false);
Graphics::setPost("exposure_compensation", 0.5);
Graphics::setPost("tonemapper", "ACES");                  // enums por su nombre (o su número)
Graphics::setPost("vignette_color", Vec3{0.2f, 0, 0});    // colores con Vec3
Graphics::setPost("contact_shadows", Graphics::getQuality().asString() != "Baja");
Graphics::setPost("volumetric_density", 0.05);

Debug::log(Graphics::getPost("fxaa").asString());
for (const Value& key : Graphics::postKeys().items()) Debug::log(key.asString());

Los cambios de la escena se deshacen al parar el Play en el editor, como cualquier otro cambio del juego.

Ejemplo: menú de opciones

#include <cramion/Script.h>
using namespace cramion;

class Opciones : public Script {
public:
    void awake() override {
        // Mensajes de los botones y casillas de la UI (on_click "OnCalidadBaja"...).
        on("OnCalidadBaja", [](const Value&) { Graphics::setQuality("Baja"); });
        on("OnCalidadUltra", [](const Value&) { Graphics::setQuality("Ultra"); });
        on("OnPantallaCompleta", [](const Value& activa) {
            Graphics::set("window_mode", activa.asBool() ? "fullscreen" : "maximized");
        });
        on("OnVSync", [](const Value& activo) { Graphics::set("vsync", activo.asBool()); });
        on("OnTexturas", [](const Value& nivel) {   // "low", "medium", "high"...
            Graphics::setTextureQuality(nivel);
            Scene::load(Scene::name());                // recargar para ver las texturas nuevas
        });
        on("OnFiltrado", [](const Value& muestras) {  // 1 (apagado), 2, 4, 8, 16 o 0 (auto)
            Graphics::setTextureFiltering(muestras);   // se ve al momento
        });
        on("OnGuardar", [](const Value&) { Graphics::save(); });
    }

    void start() override {
        // Lo guardado ya se aplicó al abrir el juego; solo se muestra.
        Debug::log("Calidad: " + Graphics::getQuality().asString() + " en " + Graphics::get("gpu").asString());
    }

    // Todas las opciones con su descripción (para un menú generado).
    void listar() {
        for (const Value& o : Graphics::options().items()) {
            if (o["writable"].asBool())
                Debug::log(o["key"].asString() + " = " + o["value"].asString() + "  // " + o["description"].asString());
        }
    }
};

CRAMION_SCRIPT(Opciones)
