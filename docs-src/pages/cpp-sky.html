Color del cielo: degradado, paradas por altura y tinte del sol.

Sky

Value getColorMode(...)Physical, Gradient o GradientStops Devuelve: texto
Value getColors(...){cenit, horizonte, suelo} Devuelve: lista de Vec3
Value setBlend(valor)0 = cielo fisico .. 1 = solo los colores
Value setColorMode(texto)color del cielo: Physical (fisico), Gradient (3 colores) o GradientStops (paradas)
Value setColors(cenit, horizonte, suelo)colores del degradado (Vec3 sRGB 0..1; nil = el de antes). Pasa a Gradient si era Physical
Value setCurve(valor)curva del degradado (1 = lineal, mas = horizonte mas fino)
Value setGradient(tabla)degradado por paradas (altura en grados, hasta 8); pasa a GradientStops
Value setIntensity(valor)brillo de los colores del cielo
Value setNightColors(cenit, horizonte, suelo)colores de la noche (activa los colores por hora)
Value setSunHalo(valor)halo del sol sobre el degradado (0 = sin halo)
Value setSunTint(arg)) tinte del disco solar y su halo (blanco = sin cambio)
Value setSunsetColors(cenit, horizonte, suelo)colores del atardecer (activa los colores por hora)
Value setTimeColors(activar)mezclar dia, atardecer y noche segun la altura del sol
