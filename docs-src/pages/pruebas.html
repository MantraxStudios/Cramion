Pruebas automáticas (como el Test Runner de Unity): scripts de prueba con Test.case y Assert que se ejecutan en el editor o desde la línea de comandos (integración continua). Hay pruebas de edición (corren de golpe) y de Play (corren frame a frame en la escena: pueden esperar segundos o a que pase algo).

Escribir pruebas

Son archivos *.test.lua en cualquier carpeta de Assets (o cualquier .lua dentro de Assets/Tests). Ventana > Pruebas > Nueva prueba crea uno de ejemplo. 

Test.case("las matematicas funcionan", function()
    Assert.equal(2 + 2, 4)
    Assert.approx(math.sqrt(2), 1.41421, 0.0001)
end)

Test.case("el jugador cae al suelo", {play = true, timeout = 10}, function()
    local jugador = Scene.find("Jugador")
    Assert.notNil(jugador, "no hay jugador")
    Test.waitSeconds(2)
    Assert.less(jugador.position.y, 1.5)
end)

Test.case("la puerta se abre", {play = true}, function()
    local puerta = Scene.find("Puerta")
    puerta:sendMessage("Abrir")
    Test.waitUntil(function() return puerta.rotation.y > 80 end, 5, "la puerta no se abrio")
end)

Esperas: Test.wait(frames), Test.waitSeconds(s), Test.waitUntil(funcion, limite). Comprobaciones: Assert.isTrue/isFalse/equal/notEqual/approx/isNil/notNil/greater/less/atLeast/atMost/contains/throws/noError/fail. Una prueba falla en la primera comprobación que no se cumple (con su mensaje) o al pasar su tiempo máximo.

Test Runner

Ventana > Pruebas (Test Runner): Ejecutar todas, Solo edición o Solo Play. Entra en Play en la escena abierta, ejecuta y vuelve a Edición. Los resultados salen agrupados por archivo (✔ bien, ✖ mal, – saltada) con el mensaje, el tiempo y las comprobaciones.

Línea de comandos (CI)

CramionEditor.exe --run-tests "C:\Juegos\MiJuego" --junit resultados.xml

Abre el proyecto (con su escena inicial), ejecuta todas las pruebas, escribe cada resultado en la consola y, si se pide, un informe JUnit (lo entienden GitHub Actions, Jenkins, GitLab...) y cierra. Código de salida: 0 todas bien, 1 alguna falló, 2 no hay pruebas, 3 no se pudo abrir el proyecto.
