Conexiones WebSocket (ws/wss) con tu servidor; WsClient.

WebSocket

Value close(id, valor, texto)cierre limpio (1000, o 3000-4999 propios); no reconecta
Value closeAll(valor, texto)cierra todas las conexiones
Value connect(tabla)abre una conexion WebSocket (no espera); con name, si ya hay una viva devuelve esa Devuelve: id de la conexion (nil si no vale)
Value count(...)conexiones vivas (no cerradas) Devuelve: numero
Value find(texto)la conexion con ese nombre Devuelve: id (nil si no hay)
Value info(id)datos de la conexion Devuelve: { id, name, url, state, protocol, sent, received, sentBytes, receivedBytes, buffered, rtt, reconnects } (nil si no existe)
Value list(...)conexiones vivas Devuelve: lista de { id, name, state, url }
Value off(escucha)deja de escuchar (el numero que devolvio on)
Value on(id, texto, callback)end) escucha un evento: open, message, close, error, reconnecting o any (id o nombre) Devuelve: numero de la escucha (para off)
Value poll(id, valor)saca los eventos pendientes (si no usas on); un viaje por frame Devuelve: lista de eventos
Value send(id, texto)envia texto (UTF-8) Devuelve: true si se encolo
Value sendBinary(id, texto)envia bytes (en base64) Devuelve: true si se encolo
Value sendJson(id, tabla)envia la tabla como texto JSON Devuelve: true si se encolo
Value setHeader(id, texto, texto2)cabecera para la proxima reconexion (vacio la quita) Devuelve: true si vale
Value state(id)connecting, open, closing, closed o reconnecting Devuelve: texto ("closed" si no existe)
