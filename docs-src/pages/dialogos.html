Diálogos ramificados (como Yarn Spinner o los Dialogue Trees de Unreal): un asset .crdialog es un grafo de nodos que se edita en el editor de diálogos y se ejecuta con Dialogue.start("Mercader"). La caja de diálogo de la UI lo muestra sin escribir código.

Crear y editar

  • Proyecto > Crear > Diálogo: Vacío o Mercader de ejemplo. Doble clic lo abre.
  • Clic derecho o Espacio: crear un nodo. Arrastrar desde la salida de un nodo hasta otro lo enlaza (soltar en el vacío crea uno nuevo enlazado). Alt+clic en una entrada quita lo que llega.
  • A la derecha, los detalles del nodo; a la izquierda, las variables (compartidas por todos los diálogos y guardadas con las partidas). En los textos, {$oro} pone el valor de una variable.
  • Probar recorre el diálogo dentro del editor, sin dar Play. En Play, el nodo que corre brilla.

Nodos

NodoQué hace
InicioDonde empieza
LíneaQuién habla, el texto (o una clave de localización), un audio y si avanza solo tras unos segundos
OpcionesEl jugador elige. Cada opción puede tener una condición (oculta o deshabilitada si no se cumple)
CondiciónVa por "Sí" o por "No" según las variables (oro >= 10; $otra compara con otra variable)
VariableCambia una variable: =, +=, -= o alternar
EventoAvisa a los scripts (Dialogue.onEvent) y/o llama a un método del script de un objeto
SaltarA otro nodo o a otro diálogo
FinTermina

Caja de diálogo

El componente de UI Caja de diálogo (DialogueBox, en un objeto con RectTransform dentro de un Canvas) dibuja el panel, el nombre, el texto con efecto máquina de escribir y las opciones. Clic, Espacio o Enter siguen; 1..9 o clic eligen.

Desde los scripts

function OnTriggerEnter(self, otro)
    if otro.tag == "Player" then Dialogue.start("Mercader") end
end

Dialogue.onEvent(function(nombre, argumento)
    if nombre == "Vender" then Save.setValue("oro", Save.getValue("oro", 0) + 10) end
end)

También: Dialogue.next(), Dialogue.choose(1), Dialogue.currentLine(), Dialogue.choices(), Dialogue.setVar/getVar y los avisos onStart, onLine, onChoices y onEnd (para hacer tu propia interfaz).
