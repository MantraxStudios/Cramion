Repeticiones: grabar, reproducir, buscar, guardar y cargar.

Replay

Value duration(...)segundos grabados
Value isPlaying(...)esta reproduciendo?
Value isRecording(...)esta grabando?
Value list(...)repeticiones guardadas
Value load(texto)carga un .crreplay
Value mark(texto, datos)marcador en la linea de tiempo
Value pause(activar)pausa la reproduccion
Value play(desde, velocidad)reproduce (desde < 0 = los ultimos N segundos)
Value save(texto)guarda un .crreplay
Value seek(segundos)salta a ese momento
Value setFreeCamera(activar)camara libre (WASD + raton)
Value setLoop(activar)en bucle
Value setSpeed(valor)camara lenta / rapida
Value start(tabla)empieza a grabar
Value stop(...)deja de grabar
Value stopPlayback(...)vuelve al juego
Value time(...)segundo de la reproduccion
