Input Actions

(Lua, obsoleto) Entrada como el Enhanced Input de Unreal: acciones Bool/float/Vec2/Vec3, varios contextos, muchas teclas por acción, modificadores y triggers.

En esta página
Lua está obsoleto. Sigue funcionando en los proyectos que lo usan, pero lo nuevo se escribe en C++: ver la API de C++ y Tu primer script.

Como el Enhanced Input de Unreal: en vez de preguntar por teclas sueltas, el juego define acciones (lo que hace el jugador) y contextos (qué teclas, botones o ejes las activan). Una acción puede tener muchas teclas a la vez (teclado, ratón, mando y joystick táctil), y puedes tener varias configuraciones (a pie, vehículo, vuelo, menú...) y activarlas o desactivarlas desde Lua.

Dónde se configura

En Archivo > Entrada del proyecto (acciones y teclas). Todo se guarda al momento en ProjectSettings/InputActions.json y el juego exportado (PC y Android) lo carga solo. En Play los cambios se aplican al instante. La ventana tiene tres pestañas:

  • Acciones (Input Actions): nombre, tipo de valor, descripción, cómo se combinan varias teclas, modificadores y triggers de la acción.
  • Contextos (Mapping Contexts): nombre, prioridad, si está activo al empezar y, por cada acción, su lista de teclas. Cada tecla tiene sus propios modificadores y triggers. El botón ... junto a una tecla (o + tecla) espera a que pulses la tecla o el botón del mando; Escape cancela.
  • Depurar (Play): el estado (none / ongoing / triggered), el valor y el tiempo de cada acción, y los contextos activos.

Un proyecto sin archivo usa la configuración por defecto (se puede editar a partir de ella):

AcciónTipoTeclas (contexto Default)
MoveAxis2D (Vec2)W/A/S/D, flechas, stick izquierdo, cruceta, joystick táctil, stick izquierdo de VR. x derecha, y adelante.
LookAxis2D (Vec2)Ratón (o arrastrar el dedo), stick derecho y stick derecho de VR (solo girar). Misma escala que getAxis("Mouse X").
JumpBoolSpace, mando A, VR A (derecha).
SprintBoolLeftShift, mando LS, pulsar el stick izquierdo de VR.
FireBoolClic izquierdo, gatillo RT, gatillo derecho de VR.
AimBoolClic derecho, gatillo LT, gatillo izquierdo de VR.
InteractBool (trigger Pressed)E, mando X, agarre derecho de VR.
ZoomAxis1D (float)Rueda del ratón, RB (+) / LB (−).
FlyAxis3D (Vec3)Contexto Vuelo (prioridad 1, inactivo al empezar): W/S → z, D/A → x, E/Q → y, stick izquierdo, RB/LB.

Tipos de valor

TipoEn Lua (Input.getAction)Ejemplo
Bool (digital)true / falseSaltar, disparar, usar.
Axis1D (float)númeroAcelerador, zoom, girar un volante.
Axis2D (Vec2)Vec3 con x, y (z = 0)Andar, mirar.
Axis3D (Vec3)Vec3Volar, nadar, cámara libre.

Cada tecla da un valor: un botón da 1 en x; un eje (Gamepad LT, Mouse Wheel) un número en x; un stick (Gamepad Left Stick, Mouse XY, Touch Stick) x e y. Los modificadores lo llevan al eje que toca. Con varias teclas pulsadas a la vez, por defecto se toma el mayor valor en cada sentido (W + S = 0; W + flecha arriba = 1, no 2); la opción Sumar las suma.

Nombres de teclas, botones y ejes

Teclado"W", "Space", "LeftShift", "Enter", "F1", "1", "Up", "Keypad0"... (alias: "Shift", "Ctrl", "Esc")
Ratón"Mouse Left", "Mouse Right", "Mouse Middle", "Mouse X1", "Mouse X2"; ejes "Mouse X", "Mouse Y" (positivo hacia arriba), "Mouse XY" (2D, píxeles del frame) y "Mouse Wheel"
Mando"Gamepad A", "Gamepad B", "Gamepad X", "Gamepad Y", "Gamepad LB", "Gamepad RB", "Gamepad LS", "Gamepad RS", "Gamepad Start", "Gamepad Back", "Gamepad DPad Up/Down/Left/Right"; ejes "Gamepad LT", "Gamepad RT", "Gamepad Left X/Y", "Gamepad Right X/Y"; sticks 2D "Gamepad Left Stick", "Gamepad Right Stick"
Táctil"Touch Stick" (2D, el joystick en pantalla). Los botones táctiles pulsan teclas, así que se asignan con su tecla.
Realidad virtualSticks 2D "XR Left Stick", "XR Right Stick" (o el trackpad del Vive); ejes "XR Left Trigger", "XR Right Trigger", "XR Left Grip", "XR Right Grip" (0..1), "XR Left Stick X/Y", "XR Right Stick X/Y"; botones "XR Left Primary" / "XR Right Primary" (X / A), "XR Left Secondary" / "XR Right Secondary" (Y / B), "XR Left Stick Click", "XR Left Menu", "XR Right Trigger Click", "XR Right Grip Click"... Ver Realidad virtual.

No distinguen mayúsculas ni espacios ("gamepad left stick" vale).

Modificadores

Se aplican en orden: primero los de la tecla y luego los de la acción.

NegateCambia el signo de los ejes marcados (X, Y, Z). A en Move = Negate → (−1, 0).
SwizzleReordena los ejes. YXZ: una tecla 1D mueve la Y (W en un Vec2 = adelante). ZYX: a la Z (adelante en un Vec3). XZY: la Y de un stick pasa a Z. También YZX y ZXY.
Dead ZoneIgnora el valor por debajo de Min y reescala hasta Max. Radial usa la magnitud (sticks); si no, cada eje por separado.
ScaleMultiplica cada eje (sensibilidad del ratón o del stick).

Ejemplo: Move (Vec2) = W [Swizzle YXZ], S [Swizzle YXZ, Negate], D, A [Negate], Gamepad Left Stick [Dead Zone].

Triggers

Deciden cuándo se dispara la acción. Sin triggers, está disparada mientras tiene valor (Bool: a partir de 0.5). Umbral es la magnitud mínima para contar como pulsado.

DownCada frame mientras está pulsada.
PressedSolo el frame en que se pulsa.
ReleasedSolo el frame en que se suelta (en curso mientras se mantiene).
HoldTras mantenerla s segundos. Una vez: dispara una vez; si no, cada frame desde entonces.
Hold And ReleaseAl soltar, si se mantuvo al menos s segundos (cargar un arco).
TapAl soltar, si se soltó antes de s segundos; si se mantiene más, se cancela.
PulseCada s segundos mientras se mantiene (disparo automático). Al empezar dispara también al pulsar; Límite 0 = sin límite.
ChordSolo si otra acción está disparada a la vez (Ctrl + C: la acción Copiar con Chord de Modificador).

Cada frame la acción puede lanzar estos eventos (como ETriggerEvent de Unreal):

startedEmpezó (el primer frame con valor o en curso).
ongoingEn curso sin disparar todavía (manteniendo un Hold).
triggeredDisparada.
completedTerminó después de dispararse.
canceledTerminó sin llegar a dispararse (se soltó un Hold antes de tiempo).

Contextos y prioridad

Puede haber varios contextos activos a la vez. Si dos comparten una tecla, el de más prioridad se la queda (si su acción tiene Consumir las teclas, activo por defecto) y el otro no la recibe. A igual prioridad gana el último añadido. Ej.: con Vuelo (prioridad 1) activo, W mueve Fly y no Move; al quitarlo, vuelve a Move.

API de Lua

Input.getAction(accion)Valor según su tipo: true/false, número o Vec3. nil (y un aviso) si no existe.
Input.getActionValue(accion)Siempre un Vec3.
Input.getActionState(accion)"none", "ongoing" o "triggered".
Input.isActionTriggered(accion)Disparada este frame (respeta los triggers: con Pressed, solo el frame de la pulsación).
Input.isActionOngoing(accion)En curso sin disparar.
Input.wasActionStarted(accion), …Completed, …CanceledEse evento pasó este frame.
Input.getActionElapsed(accion)Segundos desde que empezó (cuánto se lleva manteniendo).
Input.bindAction(accion, evento, funcion)Llama a funcion(valor, segundos) cuando pasa el evento ("started", "ongoing", "triggered", "completed", "canceled"), antes de los Update. Devuelve un id. Se quitan solas al parar el juego o cambiar de escena.
Input.unbindAction(id)Quita un bindAction.
Input.getActions()Lista con los nombres de las acciones.
Input.addMappingContext(nombre [, prioridad])Activa un contexto (con su prioridad o la que se pase). false si no existe.
Input.removeMappingContext(nombre)Lo desactiva.
Input.hasMappingContext(nombre)Si está activo.
Input.clearMappingContexts()Desactiva todos (nada responde hasta añadir uno).
Input.getMappingContexts()Los activos, de más a menos prioridad.
Input.getBindings(accion)Lista de {context=, key=} con sus teclas en todos los contextos.
Input.rebind(contexto, accion, n, tecla)Cambia la tecla número n (1 = la primera) de esa acción en ese contexto. false si no existe, la tecla no es válida o la tecla no es cambiable por el jugador.
Input.saveBindings()Guarda las teclas cambiadas (con los Prefs del juego): se cargan solas en la próxima partida.
Input.resetBindings()Vuelve a las teclas del proyecto y borra las guardadas.
Input.anyKeyPressed()La tecla o botón pulsado este frame ("W", "Mouse Left", "Gamepad A") o nil. Para menús de "pulsa una tecla".
Input.getAxis(accion)También vale con el nombre de una acción: su x.

Ejemplos

Personaje con Move (Vec2), Look (Vec2), Jump (Bool) y Zoom (float):

local Jugador = { properties = { velocidad = 5.0, sensibilidad = 2.0 } }

function Jugador:Awake()
    self.yaw = 0
    -- Evento: una vez al pulsar (vale cualquier tecla de Jump: Space, mando A, boton tactil)
    Input.bindAction("Jump", "started", function()
        self.entity:addImpulse(Vec3(0, 5, 0))
    end)
end

function Jugador:Update(dt)
    local mover = Input.getAction("Move")      -- Vec3: x derecha, y adelante
    local mirar = Input.getAction("Look")      -- Vec3: x girar, y arriba
    local zoom  = Input.getAction("Zoom")      -- numero
    local rapidez = self.velocidad
    if Input.getAction("Sprint") then rapidez = rapidez * 2 end  -- Bool

    self.yaw = self.yaw - mirar.x * self.sensibilidad
    self.entity.rotation = Vec3(0, self.yaw, 0)
    local dir = self.entity.right * mover.x + self.entity.forward * mover.y
    self.entity:translate(dir * rapidez * dt)
end

return Jugador

Cambiar de configuración: subir a un vehículo o ponerse a volar (Vec3):

function Jugador:Update(dt)
    if Input.isActionTriggered("Interact") then          -- trigger Pressed: una vez
        if Input.hasMappingContext("Vuelo") then
            Input.removeMappingContext("Vuelo")
        else
            Input.addMappingContext("Vuelo")             -- prioridad 1: se queda W/A/S/D/E/Q
        end
    end
    if Input.hasMappingContext("Vuelo") then
        local v = Input.getAction("Fly")                 -- Vec3: x derecha, y arriba, z adelante
        self.entity:translate(Vec3(v.x, v.y, v.z) * 8 * dt)
    end
end

Mantener para cargar (trigger Hold And Release de 0.6 s en la acción Fire):

Input.bindAction("Fire", "ongoing", function(v, t)
    Debug.log("cargando " .. string.format("%.1f", t))
end)
Input.bindAction("Fire", "triggered", function() self:dispararFuerte() end)
Input.bindAction("Fire", "canceled", function() self:dispararNormal() end)

Menú de opciones: "pulsa una tecla" para cambiar el salto y guardarlo:

function Opciones:Update(dt)
    if self.esperando then
        local tecla = Input.anyKeyPressed()
        if tecla == "Escape" then
            self.esperando = false
        elseif tecla then
            if Input.rebind("Default", "Jump", 1, tecla) then
                Input.saveBindings()
            end
            self.esperando = false
        end
    end
end

function Opciones:mostrarTeclas()
    for _, b in ipairs(Input.getBindings("Jump")) do
        Debug.log(b.context .. ": " .. b.key)
    end
end

Las funciones de siempre (Input.getKey, getAxis("Horizontal")...) siguen funcionando; se pueden mezclar con las acciones.
