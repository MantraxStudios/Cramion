Graphics

Configuración gráfica y post-procesado desde Lua: calidad, resolución, sombras, texturas, ventana.

Graphics cambia la configuración gráfica desde un script, como el QualitySettings y el Screen de Unity juntos: calidad rápida, escalado y resolución, nitidez, VSync, FPS objetivo, sombras, texturas, trazado de rayos, ventana y el post-procesado de la escena. Todo lo que hay en Ajustes de render y en el componente PostProcessing se puede tocar desde Lua; sirve para montar el menú de opciones del juego. 

Graphics.setQuality("Alta")           -- Baja, Media, Alta, Ultra (o 0..3)
Graphics.vsync = true                  -- cualquier opción por su nombre
Graphics.texture_quality = "high"
Graphics.set{ shadow_quality = "ultra", target_fps = 144 }   -- varias a la vez
Graphics.post.bloom = false            -- post-procesado de la escena
Graphics.save()                        -- el juego lo recuerda la próxima vez

Funciones

FunciónQué hace
Graphics.setQuality(nivel)Calidad rápida: "Baja", "Media", "Alta", "Ultra" (también "low"... o un número 0..3). Ajusta escalado, resolución, nitidez, sombras, sonda de reflexión y trazado de rayos a la vez, igual que los botones del editor.
Graphics.getQuality()La última calidad rápida aplicada, o "Personalizada" si luego se cambió algo suelto.
Graphics.qualityLevels()Lista de calidades (para un desplegable).
Graphics.set(clave, valor)
Graphics.set{ clave = valor, ... }		Cambia una o varias opciones. Devuelve true si se aplicaron; si no, avisa en la Consola por qué (clave que no existe, de solo lectura, valor fuera de la lista).
Graphics.get(clave)El valor actual (o nil).
Graphics.clave / Graphics.clave = valorLo mismo con la sintaxis de propiedad: Graphics.vsync, Graphics.upscaler = "fsr1".
Graphics.getAll()Tabla clave → valor con todo.
Graphics.options()Lista para construir un menú: cada elemento tiene key, value, writable, description y, si es de una lista, choices.
Graphics.resolutions()Resoluciones del monitor, de mayor a menor: { {width = 1920, height = 1080}, ... }.
Graphics.save()En el juego exportado guarda la configuración del jugador (incluida la ventana) en %LOCALAPPDATA%/Cramion/Saves/<juego>.graphics.ini. Al volver a abrir el juego se aplica encima de la de ProjectSettings/Graphics.ini. En el editor no guarda nada.

De solo lectura: gpu, hardware_tier, vram_mb, vram_used_mb, ray_tracing_supported, render_width/render_height (resolución interna), screen_width/screen_height (salida) y gpu_ms (milisegundos de GPU por frame). De la vegetación: foliage_trees (árboles en la GPU), foliage_visible (dibujados el último frame), foliage_near (con todo el detalle) y foliage_triangles.

Texturas: texture_quality se aplica a los modelos que se cargan después. En un menú de opciones, vuelve a cargar la escena para verlo: Scene.load(Scene.name()).
Presupuesto adaptativo: con adaptive = true el motor puede bajar sombras, efectos o resolución por su cuenta si no llega a los FPS; para que se quede exactamente lo que elige el jugador, desactívalo.
En el editor: lo que cambien los scripts en Play se deshace al parar; la ventana no se toca.

Post-procesado: Graphics.post

Graphics.post lee y cambia el volumen de post-procesado global de la escena (el de mayor prioridad; si la escena no tiene, se crea uno). Las claves son las del componente PostProcessing: exposición, tonemapping, color, bloom, viñeta, lente, rayos de sol, SSAO, GI, reflejos, sombras de contacto, luz volumétrica, LODs, FXAA... Graphics.postKeys() devuelve la lista completa. 

Graphics.post.bloom = false
Graphics.post.exposure_compensation = 0.5
Graphics.post.tonemapper = "ACES"                -- enums por su nombre (o su número)
Graphics.post.vignette_color = Vec3(0.2, 0, 0)   -- colores con Vec3
Graphics.post.contact_shadows = Graphics.getQuality() ~= "Baja"

Graphics.setPost("volumetric_density", 0.05)     -- igual, con funciones
Debug.log(Graphics.getPost("fxaa"))
for _, key in ipairs(Graphics.postKeys()) do Debug.log(key) end

Los cambios de la escena se deshacen al parar el Play en el editor, como cualquier otro cambio del juego.

Ejemplo: menú de opciones

local Opciones = {}

function Opciones:Start()
    -- Lo guardado ya se aplico al abrir el juego; solo se muestra.
    Debug.log("Calidad: " .. Graphics.getQuality() .. " en " .. Graphics.gpu)
end

-- Conectados a botones y casillas de la UI (eventos que llaman a metodos).
function Opciones:CalidadBaja()  Graphics.setQuality("Baja")  end
function Opciones:CalidadUltra() Graphics.setQuality("Ultra") end
function Opciones:PantallaCompleta(activa)
    Graphics.window_mode = activa and "fullscreen" or "maximized"
end
function Opciones:VSync(activo) Graphics.vsync = activo end
function Opciones:Texturas(nivel)          -- "low", "medium", "high"...
    Graphics.texture_quality = nivel
    Scene.load(Scene.name())               -- recargar para ver las texturas nuevas
end
function Opciones:Guardar() Graphics.save() end

-- Todas las opciones con su descripcion (para un menu generado).
function Opciones:Listar()
    for _, o in ipairs(Graphics.options()) do
        if o.writable then Debug.log(o.key .. " = " .. tostring(o.value) .. "  -- " .. o.description) end
    end
end

return Opciones
