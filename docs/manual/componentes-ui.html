Interfaz (UI)

Canvas, rectangulos, imagenes, textos, botones, sliders, casillas y campos. Referencia completa generada desde el motor.

Canvas UICanvas

La raiz de una interfaz: todo lo que cuelga de el se dibuja encima del juego. Referencia es la resolucion de diseno (1920x1080) y se escala con la pantalla.

PropiedadTipoPor defectoValoresDescripcion
Resolucion de referencia

Escalado

Ajustar a

Orden
sort_order		entero0-100 a 100

Rect Transform RectTransform

Rectangulo de un elemento de interfaz: anclas (0..1 del padre), pivote, posicion desde el ancla y tamano. Anclas separadas estiran el elemento con su padre. Desde Lua: uiPosition y uiSize.

PropiedadTipoPor defectoValoresDescripcion
Ancla min
anchor_min		Vec2(0,5; 0,5)0..1 del padre (0,0 = arriba izquierda)
Ancla max
anchor_max		Vec2(0,5; 0,5)
Pivote
pivot		Vec2(0,5; 0,5)
Posicion
position		Vec2(0; 0)
Tamano
size		Vec2(200; 60)Con anclas separadas se suma al hueco entre ellas
