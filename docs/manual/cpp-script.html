Script y propiedades

La clase Script, sus eventos, Property<T> y sus opciones, assets y archivos.

En esta página

Cada script es una clase que hereda de Script y se registra con CRAMION_SCRIPT(Clase). Ver también Scripts en C++.

Script: eventos

Entity entity() const
Value property(const std::string& name) const
T property(const std::string& name, T fallback) const
std::string property(const std::string& name, const char* fallback) const
void awake()Al crearse el script (antes de start).
void start()Una vez, antes del primer update.
void update(float )Cada frame (dt = segundos desde el anterior).
void fixedUpdate(float )Cada paso de la fisica.
void lateUpdate(float )Cada frame, despues de todos los update (camaras).
void onDestroy()Al destruirse el objeto o parar el juego.
void onCollisionEnter(const Collision&)Empieza un choque con otro objeto.
void onCollisionStay(const Collision&)Sigue el choque.
void onCollisionExit(const Collision&)Termina el choque.
void onTriggerEnter(Entity )Otro objeto entra en un trigger.
void onTriggerStay(Entity )Otro objeto sigue dentro del trigger.
void onTriggerExit(Entity )Otro objeto sale del trigger.
void onMessage(const std::string& name, const Value& value)Un mensaje por su nombre: los botones (on_click "OnJugar"), sliders, casillas y campos de la UI lo envian al script del objeto. Por defecto llama al de on(...).
void onOriginShift(const Vec3& )Mundos grandes: el motor recoloco el origen y todo se movio -offset (resta offset a las posiciones guardadas).
void onNetVar(const std::string& , const Value& )Objeto de red: llego un cambio de una variable sincronizada (setNetVar del dueno o del servidor).
Value onBeforeReload()Recarga en caliente (guardaste el .cpp en Play): lo que devuelvas aqui llega a onAfterReload de la instancia nueva. Las Property<T> se conservan solas; guarda aqui el resto (variables privadas).
void onAfterReload(const Value& )Recarga en caliente: la instancia nueva ya tiene sus Property<T>; no se llama awake() ni start(). Vuelve a registrar aqui los callbacks (Input.bindAction, Network.on...) del proceso anterior.
void on(const std::string& name, std::function<void(const Value&)> fn)Que hacer con un mensaje (en el constructor o en awake): on("OnJugar", [this](const Value&) { Scene::load("Nivel1"); }); on("OnVolumen", [this](const Value& v) { Prefs::setFloat("volumen", v); });
