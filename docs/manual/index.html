Manual de Cramion

El manual de Cramion: cómo se usa el editor (paneles, herramientas, materiales, render y exportar), la referencia de todos los componentes con cada propiedad, y la API de Lua para programar el juego: cada script es una tabla, cada entidad con un componente Script recibe su propia instancia (self) y el motor llama a sus métodos durante el modo Play.

Tu primer script Referencia de la API Ejemplos Exportar el juego

00Empieza aquí

  1. Crea un script. Proyecto > Crear > Script Lua, o Nuevo script en el Inspector.
  2. Engánchalo a un objeto. Arrastra el .lua a un objeto de la Jerarquía o de la Escena.
  3. Dale a Play. El motor llama a Start, Update(dt)... Guarda con Ctrl+S y se recarga en caliente (ciclo de vida).

04Referencia de la API

Todo lo que se puede usar desde Lua, por tema.

  • Vec3Vectores 3D: operaciones, ángulos, interpolación, suavizado y proyecciones.
  • Quat (rotaciones)Rotaciones sin bloqueo de cardán: mirar hacia, girar con velocidad fija, interpolar.
  • MathfLimitar, interpolar, suavizar, ángulos, trigonometría y ruido Perlin.
  • RandomAleatorios con semilla: rangos, probabilidades, direcciones, listas.
  • EntityTransformación, jerarquía, física, sonido, animación e interfaz de un objeto.
  • SceneBuscar, crear, instanciar y destruir objetos; cambiar de escena.
  • InputTeclado, ratón, ejes y mando.
  • Input ActionsEntrada como el Enhanced Input de Unreal: acciones Bool/float/Vec2/Vec3, varios contextos, muchas teclas por acción, modificadores y triggers.
  • Realidad virtual (XR)OpenXR: jugar con casco (SteamVR, Meta Quest Link, WMR...), XR Origin, mandos, vibración y la tabla XR.
  • TimeTiempo del frame, tiempo total y escala de tiempo.
  • PhysicsRaycasts y consultas a la física.
  • NavegaciónNavMesh: agentes que buscan el camino.
  • Mallas por códigoCrea y modifica mallas con varios materiales desde Lua.
  • Mundo de bloquesLeer y cambiar bloques de un mundo voxel.
  • AudioSonidos, efectos, oclusion por paredes y zonas de reverberacion.
  • Interfaz (UI)Textos, botones e imágenes en pantalla.
  • Esqueletos: IK, ragdoll y phys bonesVer y mover huesos, sockets, IK de humanos y animales, Phys Bones, ragdoll y campos de componentes desde Lua.
  • GraphicsConfiguración gráfica y post-procesado desde Lua: calidad, resolución, sombras, texturas, ventana.
  • Network (multijugador)Partidas por red: crear y unirse, mensajes, objetos y variables sincronizados.
  • Http y JsonEnviar y recibir datos de servidores y webs por HTTPS, de forma segura; JSON a tablas.
  • Prefs y GameDatos guardados entre partidas y salir del juego.
  • DebugMensajes, avisos y errores en la consola del editor.

06Ejemplos

Scripts completos listos para copiar a Assets/Scripts/.

  • Girar un objetoAspas de molino, monedas, plataformas… El eje y la velocidad se ajustan en el Inspector.
  • Cámara que sigue al jugadorSe ejecuta en LateUpdate para moverse después de que el jugador ya se movió en su Update.
  • Jugador con físicaMovimiento con WASD y salto con Espacio sobre un Rigidbody con CapsuleCollider. Detecta el suelo con un raycast y fija la velocidad horizontal para que el control sea preciso.
  • Disparo con raycastAl hacer clic, lanza un rayo desde la cámara hacia delante y empuja lo que toque.
  • Monedas y puntuaciónCada moneda tiene un SphereCollider marcado como trigger y la etiqueta Moneda. El marcador es una entidad con un UIText llamada Marcador.
  • Generador de enemigosUsa una entidad desactivada como plantilla (un "prefab" dentro de la escena) y la copia con Scene.instantiate cada cierto tiempo en un punto aleatorio.
  • Conducir un vehículoEn una entidad con Rigidbody, Vehicle y ruedas con WheelCollider. Muestra la velocidad en un UIText llamado Velocimetro.
  • Menú, opciones y récordEl método OnJugar se conecta al UIButton "Jugar", OnVolumen a un UISlider y OnSalir al botón "Salir". El volumen y el récord se guardan con Prefs.
  • Animación de un personajeAlimenta los parámetros del controlador de animación a partir de la velocidad del Rigidbody.
  • Scripts que se hablanentity:getScript() devuelve la instancia del script de otra entidad: puedes leer sus datos y llamar a sus métodos. Así, un gestor de nivel puede coordinar a los demás.
  • IA: patrullar y perseguirUn guardia con NavAgent que patrulla por puntos al azar y persigue al jugador cuando lo ve (el raycast de la malla comprueba que no haya una pared en medio). Si lo pierde, vuelve a patrullar.

  • Varios materiales y efectosScript completo listo para copiar.
  • Olas: cambiar la malla cada frameScript completo listo para copiar.
