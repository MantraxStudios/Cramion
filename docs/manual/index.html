Documentación de Cramion

El manual de Cramion: cómo se usa el editor (paneles, herramientas, materiales, render y exportar), la referencia de todos los componentes con cada propiedad, y la API de Lua para programar el juego: cada script es una tabla, cada entidad con un componente Script recibe su propia instancia (self) y el motor llama a sus métodos durante el modo Play.

Empezar Referencia de la API

Empieza aquí

Tu primer script en tres pasos.

  1. Crea un script. Proyecto > Crear > Script Lua, o Nuevo script en el Inspector.
  2. Engánchalo a un objeto. Arrastra el .lua a un objeto de la Jerarquía o de la Escena.
  3. Dale a Play. El motor llama a Start, Update(dt)... Guarda con Ctrl+S y se recarga en caliente (ciclo de vida).
