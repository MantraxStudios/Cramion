Conectar una IA (MCP)

Claude, Cursor o Copilot trabajando dentro del editor: escenas, scripts, shaders y modelos.

Cramion Editor trae un servidor MCP (Model Context Protocol, el estándar abierto para conectar IA con herramientas). Con él, una IA como Claude, Cursor o Copilot trabaja dentro del motor: crea escenas y objetos, escribe scripts Lua y shaders, hace materiales y modelos, le da a Play, lee la consola y mira capturas para comprobar el resultado. Tú ves cada cambio en el editor al momento y puedes deshacerlo con Ctrl+Z.

Activarlo

El servidor arranca solo al abrir el editor, en http://127.0.0.1:7777/mcp. Lo ves en Ventana > MCP (IA) (o Ayuda > Conectar una IA): estado, dirección, botones para copiar la configuración de cada cliente y la actividad de la IA.

Solo acepta conexiones de tu propio PC y rechaza las que vienen de páginas web. Si el puerto 7777 está ocupado (otro editor abierto) usa el siguiente libre; la ventana del MCP muestra cuál. Con la variable de entorno CRAMION_MCP_PORT eliges otro.

Terminal integrada (IA sin salir del motor)

Ventana > Terminal (IA) abre consolas de Windows de verdad dentro del editor, con pestañas. El botón Claude Code lo arranca en la carpeta del proyecto y ya conectado a este editor por MCP (no toca tu configuración global de Claude): le pides "crea una plaza con farolas y que sea de noche" y lo ves hacerlo en la escena. También hay PowerShell y, en Más..., CMD, Codex, Gemini CLI e Instalar Claude Code.

  • Copiar: selecciona con el ratón y Ctrl+C (sin selección, Ctrl+C interrumpe como en cualquier terminal). Pegar: Ctrl+V o clic derecho.
  • Historial: rueda del ratón o Shift+RePág / Shift+AvPág.
  • Mientras escribes en la terminal los atajos del editor (Supr, W/E/R, Ctrl+S...) no se disparan.

Claude Code

En una terminal externa (con el editor abierto):

claude mcp add --transport http cramion http://127.0.0.1:7777/mcp

Cursor, VS Code, Windsurf

En su archivo de servidores MCP (.cursor/mcp.json, .vscode/mcp.json...):

{
  "mcpServers": {
    "cramion": { "url": "http://127.0.0.1:7777/mcp" }
  }
}

Claude Desktop (y clientes por stdio)

Los clientes que lanzan un programa usan CramionMcp.exe, que viene junto al editor y hace de puente. En claude_desktop_config.json (la ruta exacta la copia el botón de la ventana MCP): 

{
  "mcpServers": {
    "cramion": {
      "command": "C:\\Cramion\\CramionMcp.exe",
      "args": ["--port", "7777"]
    }
  }
}

Si el editor está cerrado, el puente contesta a la IA que lo abras.

Qué puede hacer la IA

HerramientasPara qué
help, editor_stateGuía del motor para la IA y qué hay abierto.
list_projects, open_project, create_projectProyectos y plantillas.
list_entities, get_entityVer la escena y cada objeto con todos sus componentes.
create_entity, modify_entity, delete_entity, duplicate_entityCrear primitivas, luces, cámaras, terreno, agua, vehículos, mundos de bloques; mover, girar, emparentar.
list_component_types, set_component, remove_componentCualquier componente del motor y cualquiera de sus campos.
create_script, create_shader, read_file, write_fileEscribir scripts Lua y shaders (con los errores de compilación de vuelta).
paint_prefabsPinta prefabs (árboles, rocas…) alrededor de un punto con densidad, separación y pendiente máxima, o los borra.
create_material, assign_materialMateriales PBR o con shader propio. Con from_image (la imagen de color de un pack de escaneos) encuentra sola las demás: normal, rugosidad o gloss, AO, displacement (parallax, height_scale en metros), cavidad, specular y bump.
create_model, import_file, instantiate, create_prefabModelos desde OBJ o archivos, ponerlos en la escena, prefabs.
new_scene, open_scene, save_scene, list_scenesEscenas.
play, stop, pause, run_luaProbar el juego y consultar su estado desde Lua.
get_console, screenshotVer errores y el resultado en imagen.
select, inspect_asset, set_camera, set_gizmo, undo, redoEnseñarte algo en el editor y deshacer.

Qué pedirle

  • "Crea un nivel de plataformas con 10 plataformas a distintas alturas, monedas que giran y un jugador con cámara en tercera persona."
  • "Haz un shader de lava para el suelo y un material con él; pruébalo y mándame una captura."
  • "El jugador atraviesa las paredes: mira la escena y los scripts y arréglalo."
  • "Convierte este enemigo en un prefab y pon 5 copias que patrullen con el NavMesh."
Consejo: pídele que llame primero a help y a editor_state. Todo lo que hace la IA pasa por el deshacer del editor, pero guarda tu escena antes de pedirle cambios grandes.
