Http y Json

Enviar y recibir datos de servidores y webs por HTTPS, de forma segura; JSON a tablas.

Http manda y recibe datos de servidores y webs por HTTPS: tu propia API, un marcador de puntuaciones online, cuentas de jugador, noticias del juego o telemetría. Las peticiones van en segundo plano (el juego no se para) y la respuesta llega a una función que se llama en el hilo del juego, como un Update más. Json convierte entre tablas de Lua y texto JSON. 

-- Leer
Http.get("https://api.mijuego.com/noticias", function(res)
    if not res.ok then
        print("No se pudo: " .. res.error)
        return
    end
    for _, n in ipairs(res.data.noticias) do print(n.titulo) end   -- res.data = JSON ya decodificado
end)

-- Enviar una tabla (va como JSON)
Http.post("https://api.mijuego.com/puntos", { jugador = "Ana", puntos = 1200 }, function(res)
    print(res.status)          -- 201
end, { Authorization = "Bearer " .. token })

Seguridad

  • Solo https://, con TLS 1.2 o 1.3. Windows comprueba el certificado del servidor: si está caducado, es de otro dominio o no es de una autoridad de confianza, la petición falla y no se envía nada.
  • http:// sin cifrar solo se permite a localhost / 127.0.0.1, para probar con un servidor en tu PC.
  • Las redirecciones nunca pasan de https a http.
  • Las cabeceras no pueden llevar saltos de línea (no se pueden colar otras cabeceras).
  • Cada petición tiene un tiempo máximo (20 s por defecto) y un tamaño máximo de respuesta (32 MB): un servidor que no contesta o que manda datos sin fin no bloquea ni llena la memoria.
  • Al salir de Play (o al cambiar de escena) lo que queda pendiente se cancela.

No pongas claves secretas en los scripts (la de tu base de datos, la de administrador de una API): los scripts van dentro del juego exportado y cualquiera puede sacarlas. El juego debe hablar con tu servidor, que es quien guarda las claves y comprueba lo que llega (que nadie mande 99999 puntos). Para identificar a un jugador usa un token que le dé tu servidor al iniciar sesión.

Funciones

FunciónQué hace
Http.get(url, funcion, cabeceras)Petición GET. cabeceras (opcional) es una tabla { Nombre = "valor" }. Devuelve el id de la petición, o nil, motivo si la dirección no vale (por ejemplo http:// a Internet).
Http.post(url, datos, funcion, cabeceras)Petición POST. datos: un texto (se manda tal cual, text/plain) o una tabla (se manda como JSON, application/json). Una Content-Type propia en las cabeceras manda sobre esas.
Http.request(opciones, funcion)Cualquier método: { url, method = "PUT"/"PATCH"/"DELETE"..., headers, body, timeout = 20 (segundos), maxSize = bytes }.
Http.pending()Peticiones sin terminar.
Http.cancelAll()Cancela todas (sus funciones ya no se llaman).
Http.urlEncode(texto)Texto seguro para meterlo en una URL: "hola mundo" → "hola%20mundo".
Http.query(tabla)Parámetros de consulta: Http.query{ q = "ana", page = 2 } → "page=2&q=ana".
Json.encode(valor, bonito)Tabla → texto JSON. Una tabla con claves 1..n es una lista; si no, un objeto. Vec3 sale como {x, y, z}. bonito = true lo sangra. Devuelve nil, motivo si hay algo que no se puede pasar (funciones).
Json.decode(texto)Texto JSON → tabla (las listas desde 1; null pasa a nil). nil, motivo si no es JSON.

La respuesta

CampoQué es
res.oktrue si llegó respuesta con estado 2xx.
res.statusEstado HTTP (200, 201, 404, 500...). 0 si no hubo respuesta (sin Internet, certificado malo, tiempo agotado).
res.bodyEl cuerpo como texto.
res.dataSi la respuesta es JSON, ya decodificada en tablas.
res.headersCabeceras de la respuesta, con el nombre en minúsculas: res.headers["content-type"].
res.errorPor qué falló (texto), si no es ok.
res.timeSegundos que tardó.

Ejemplo: marcador online

local Marcador = {
    properties = { servidor = "https://api.mijuego.com" }
}

function Marcador:Start()
    self.texto = Scene.find("UI_Marcador")
    self:cargar()
end

function Marcador:cargar()
    local url = self.servidor .. "/puntos?" .. Http.query{ nivel = 1, limite = 10 }
    Http.get(url, function(res)
        if not res.ok then
            self.texto.text = "Sin conexion (" .. res.error .. ")"
            return
        end
        local lineas = {}
        for i, fila in ipairs(res.data) do
            lineas[#lineas + 1] = i .. ". " .. fila.nombre .. "  " .. fila.puntos
        end
        self.texto.text = table.concat(lineas, "\n")
    end)
end

function Marcador:enviar(nombre, puntos)
    Http.post(self.servidor .. "/puntos", { nombre = nombre, puntos = puntos }, function(res)
        if res.ok then self:cargar() end
    end, { Authorization = "Bearer " .. Prefs.getString("token", "") })
end

return Marcador

Probar con un servidor en tu PC

Mientras lo desarrollas, cualquier servidor local sirve con http://localhost:puerto (por ejemplo python -m http.server 8000 para leer archivos, o tu API con Node, Python o PHP). Para publicar el juego, pon el servidor con HTTPS (Let's Encrypt lo da gratis) y cambia la dirección.
