Qué trae

Un solo motor con todo lo de un juego completo, escrito en C++20. Lo que sigue es lo que hay hoy, no una hoja de ruta. Cada punto tiene su página en el manual.

Render CramionFX · Vulkan 1.3
Diferido con PBR metal/rugosidad. Cielo físico con día y noche que ilumina y refleja (IBL), sombras en cascada estabilizadas, sombras de contacto y de luces puntuales y focos, SSAO y SSGI, luz volumétrica con polvo iluminado, nubes y niebla por altura. Bloom, auto-exposición, TAA, FSR 1 y volúmenes de post-procesado por zonas. Materiales de escaneo con parallax, cavidad y gloss. Render Textures para pantallas, espejos y minimapas.
Rendimiento
LODs automáticos, static batching, occlusion culling y recorte por clústeres en la GPU, y un presupuesto de frame que baja lo que menos se nota para llegar a tus FPS. Escenas de unos 10 millones de triángulos; bosques de millones de árboles dibujados en la GPU con tres niveles de detalle.
Mundo
Terreno para esculpir y pintar; océano, lagos y ríos con olas que reaccionan a lo que entra; NavMesh (Recast/Detour) que se rehace en tiempo real con agentes que se esquivan; vegetación sembrada sobre el terreno; mundos de bloques infinitos con cuevas y guardado; pintar prefabs como el Foliage de Unreal.
Física y audio
Jolt: cuerpos rígidos, colliders, triggers, raycasts, vehículos con motor y marchas, ragdolls. Sonido 3D con oclusión por paredes, eco, filtros y zonas de reverberación.
Animación
Animator con Blend Trees 1D y 2D y fundidos; IK de humanos y animales (pies y patas al suelo, mirada, manos) suavizado en el tiempo; Phys Bones, sockets, huesos editables y retargeting de humanoides; cinemáticas con línea de tiempo. Importación de FBX, glTF, OBJ y DAE con Scale Factor y conversión de unidades.
Editor
Paneles acoplables, vistas Escena y Juego, pestañas para prefabs y scripts, prefabs con instancias enlazadas, shaders de superficie en GLSL que se recompilan al guardar, mallas por código, interfaz de juego y exportación con icono y ajustes propios. El juego se escribe en Lua

Un script es una tabla con Start, Update, OnTriggerEnter y lo que necesites. Sus properties salen en el Inspector y, si guardas el archivo durante el Play, se recarga sin perder el estado.

La API cubre entidades, física, navegación, audio, interfaz, animación e IK, gráficos, red y HTTPS, con autocompletado en el editor. Corre aislado: sin acceso a tus archivos.

Referencia y ejemplos
Assets/Scripts/Jugador.lua
local Jugador = {
    properties = { velocidad = 5.0, salto = 6.0 }
}

function Jugador:Update(dt)
    local mover = Vec3(Input.getAxis("Horizontal"), 0,
                       -Input.getAxis("Vertical"))
    self.entity:translate(mover * self.velocidad * dt)

    if Input.getKeyDown("space") then
        self.entity:addImpulse(Vec3.up * self.salto)
    end
end

function Jugador:OnTriggerEnter(other)
    if other.tag == "Moneda" then
        Audio.playOneShot("Audio/moneda.wav")
        other:destroy()
    end
end

return Jugador

RequisitosWindows 10/11 x64 y una GPU con Vulkan 1.3. Las escenas de demostración no van incluidas.

Compilarlo

Hace falta Windows 10/11 con el Windows SDK, el Vulkan SDK, CMake 3.21 o más, Clang (LLVM) y Ninja. La primera vez descarga las dependencias.

RAM: 8 GB como mínimo, 16 recomendados. Disco: unos 10 GB para Release, 16 con Debug; mejor en SSD.

Release y el zip

cmake --preset clang-ninja-release
cmake --build --preset clang-ninja-release
cmake --build --preset clang-ninja-release --target cramion_package

Ejecutar

.\build-release\CramionEditor.exe
.\build-release\cramion.exe san-miguel

Si el PC se congela al compilar

Cada archivo puede usar hasta 1,5 GB. CMake ya limita cuántos compila a la vez según tu RAM (7 con 16 GB); si aun así se atasca, bájalo con -DCRAMION_COMPILE_JOBS=3.

Tamaños medidos: LLVM ~2,9 GB, Vulkan SDK ~1,7 GB, código ~0,7 GB y build-release ~3,1 GB.
