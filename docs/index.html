El juego se escribe en Lua

Un script es una tabla con Start, Update, OnTriggerEnter y lo que necesites. Sus properties salen en el Inspector y, si guardas el archivo durante el Play, se recarga sin perder el estado.

La API cubre entidades, física, navegación, audio, interfaz, animación e IK, gráficos, red y HTTPS, con autocompletado en el editor. Corre aislado: sin acceso a tus archivos.

Referencia y ejemplos
Assets/Scripts/Jugador.lua
local Jugador = {
    properties = { velocidad = 5.0, salto = 6.0 }
}

function Jugador:Update(dt)
    local mover = Vec3(Input.getAxis("Horizontal"), 0,
                       -Input.getAxis("Vertical"))
    self.entity:translate(mover * self.velocidad * dt)

    if Input.getKeyDown("space") then
        self.entity:addImpulse(Vec3.up * self.salto)
    end
end

function Jugador:OnTriggerEnter(other)
    if other.tag == "Moneda" then
        Audio.playOneShot("Audio/moneda.wav")
        other:destroy()
    end
end

return Jugador

1.4

septiembre de 2026

  • DataPacks. Como los AssetBundles de Unity: escenas enteras u objetos con todo lo que usan en un .datapack, sin el ejecutable. Niveles descargables, DLC, mods o skins que el juego carga en marcha con DataPack.loadScene y DataPack.instantiate.
  • Empaquetar con un clic derecho. Sobre un objeto de la Jerarquía, o una escena desde el menú Archivo. Exporta en segundo plano con barra de progreso y se puede cancelar.
  • Sombras por rayos para muchas luces. Farolas, antorchas y focos con sombras trazadas y penumbra según el tamaño de la lámpara. ~0,5 ms con 16 luces.
  • Mesh shaders. Sombras del sol y geometría por meshlets: de 56 a 61 FPS en una escena grande, con la misma imagen.
  • Opacity micromaps y SER. El follaje recortado se resuelve en el hardware de rayos y el path tracing puede reordenar los hilos por material.
  • Play como Unity. Elige si al dar Play se salta a la pestaña Juego o se queda en la vista actual.
  • IntelliSense. DataPack, Screen, XR y lo que faltaba de Input, con su ayuda.
  • Corregido. El plano lejano de la cámara, y el color de lo que alumbra una farola de noche.
