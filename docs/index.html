CramionFX

Un renderizador diferido completo

Cada frame pasa por un G-buffer, una pasada de iluminación PBR y una cadena de post-proceso HDR. Cada efecto se enciende o se apaga desde código o desde el editor.

PBR metal/rugosidad

Albedo, normales, rugosidad, metal, emisión y oclusión, con materiales editables desde el editor.

Cielo atmosférico e IBL

Cielo físico con ciclo de día y noche; la luz ambiente y los reflejos salen del propio cielo.

Sombras en cascada

CSM para el sol y mapas de sombra para luces puntuales y focos, con recorte por alfa.

SSAO y SSGI

Oclusión ambiental e iluminación global en espacio de pantalla: la luz rebota en las paredes.

Post-proceso HDR

Bloom, auto-exposición por histograma, rayos de luz volumétricos, tonemapping ACES y FXAA.

Escenas enormes

Lector de OBJ en paralelo, caché binaria y frustum culling por clústeres: San Miguel carga en segundos.

Scripting en Lua

Escribe gameplay como en Unity

Cada script es una tabla con métodos Start, Update, OnCollisionEnter… Las properties aparecen en el Inspector, y al guardar el archivo en modo Play se recarga sin perder el estado.

  • ✓ Vec3, Entity, Scene, Input, Time, Physics, Navigation, Audio, Prefs, Mathf
  • ✓ Recarga en caliente y consola Lua en el editor
  • ✓ Eventos de interfaz conectados a métodos del script
  • ✓ Entorno aislado: sin acceso al sistema de archivos
Ver la referencia y los ejemplos →
Assets/Scripts/Jugador.lua 
local Jugador = {
    properties = { velocidad = 5.0, salto = 6.0 }
}

function Jugador:Update(dt)
    local mover = Vec3(Input.getAxis("Horizontal"), 0,
                       -Input.getAxis("Vertical"))
    self.entity:translate(mover * self.velocidad * dt)

    if Input.getKeyDown("space") then
        self.entity:addImpulse(Vec3.up * self.salto)
    end
end

function Jugador:OnTriggerEnter(other)
    if other.tag == "Moneda" then
        Audio.playOneShot("Audio/moneda.wav")
        other:destroy()
    end
end

return Jugador

Empezar

O compílalo tú mismo

1 · Requisitos

  • Windows 10/11 x64 con Windows SDK
  • GPU con Vulkan 1.3
  • Vulkan SDK (VULKAN_SDK)
  • CMake ≥ 3.21, Clang (LLVM) y Ninja

2 · Compilar en Release

cmake --preset clang-ninja-release
cmake --build --preset clang-ninja-release
cmake --build --preset clang-ninja-release --target cramion_package  # zip

3 · Ejecutar

.\build-release\CramionEditor.exe     # editor de escenas
.\build-release\cramion.exe san-miguel  # demo de render
