Scripting en Lua 5.4

Documentación de scripting

La lógica de juego de Cramion se escribe en Lua, con un modelo parecido a los MonoBehaviour de Unity: cada script es una tabla, cada entidad con un componente Script recibe su propia instancia (self) y el motor llama a sus métodos durante el modo Play.

Tu primer script

Los scripts viven en la carpeta Assets del proyecto (por convención, Assets/Scripts/). Desde el editor, crea uno con el menú de assets: se genera con los métodos habituales. Después añade el componente Script a una entidad y elige el archivo.

Assets/Scripts/Hola.lua

local Hola = {
    properties = {
        mensaje = "¡Hola, Cramion!",
    }
}

function Hola:Start()
    Debug.log(self.mensaje, "desde", self.entity.name)
end

function Hola:Update(dt)
end

return Hola   -- obligatorio: el script debe devolver su tabla
Importante: el archivo tiene que terminar con return <tabla>. Si no, la consola mostrará "el script debe terminar con 'return <su tabla>'".

Ciclo de vida

Todos los métodos son opcionales. El motor solo llama a los que existen.

MétodoCuándo se llama
Awake()Al crear la instancia, al entrar en Play o al instanciar la entidad.
Start()Una vez, antes del primer Update de la instancia.
Update(dt)Cada frame, después de la física. dt son los segundos del frame.
LateUpdate(dt)Cada frame, después de todos los Update. Útil para cámaras.
FixedUpdate(step)Una vez por cada paso de física del frame (paso fijo, 1/60 s por defecto).
OnCollisionEnter(other, contact)Empieza un choque con otra entidad. También OnCollisionStay y OnCollisionExit.
OnTriggerEnter(other, contact)Otra entidad entra en un collider marcado como trigger. También OnTriggerStay y OnTriggerExit.
OnDestroy()Antes de destruir la entidad, o al salir de Play.

En los eventos de física, other es la otra Entity y contact una tabla con point, normal y relativeVelocity (todos Vec3). 

function Caja:OnCollisionEnter(other, contact)
    local golpe = contact.relativeVelocity:length()
    if golpe > 4 then
        Audio.playOneShot("Audio/golpe.wav", contact.point, math.min(1, golpe / 10))
    end
end

Propiedades

La tabla properties declara los valores que se pueden editar en el Inspector, con su valor por defecto. En Play se copian a la instancia: se leen como self.nombre.

TipoEjemplo
Númerovelocidad = 5.0
Sí / noinvencible = false
Textoobjetivo = "Jugador"
Vectoreje = Vec3(0, 1, 0)

Además de las propiedades, puedes guardar cualquier dato en self (self.vida = 100). Cada entidad tiene su propia copia.

Recarga en caliente y consola

  • Si guardas un .lua durante el modo Play, se vuelve a leer: las instancias conservan sus datos (self.*) y usan las funciones nuevas.
  • Los errores se muestran en la consola del editor con el archivo y la línea; un script con errores no detiene al resto.
  • La consola del editor ejecuta Lua suelto, por ejemplo Scene.find("Jugador").position = Vec3(0, 5, 0).
  • Por seguridad, los scripts no pueden usar dofile, loadfile, io ni os.execute/os.remove. Para guardar datos usa Prefs.

Vec3

Vector de tres componentes para posiciones, direcciones, giros (en grados), escalas y colores.

local a = Vec3(1, 2, 3)
local b = Vec3()               -- (0, 0, 0)
local c = a + b * 2 - Vec3.up  -- suma, resta y escala
local d = a * Vec3(1, 0, 1)    -- producto por componentes
print(a.x, a.y, a.z, a)        -- los campos se leen y escriben

local largo = a:length()
local dir   = (b - a):normalized()
local cerca = a:distance(b) < 2
local medio = a:lerp(b, 0.5)
MiembroDescripción
x, y, zComponentes.
+ - * /, -v, ==Operadores. * acepta un número o otro Vec3.
v:length()Longitud.
v:normalized()Mismo sentido, longitud 1 (o cero si v es cero).
a:dot(b), a:cross(b)Producto escalar y vectorial.
a:distance(b)Distancia entre dos puntos.
a:lerp(b, t)Interpolación lineal.
Vec3.zero, one, up, down, left, right, forward, backConstantes. forward es (0, 0, -1).
Los Vec3 se copian por valor: self.entity.position.y = 3 no mueve la entidad. Lee, modifica y vuelve a asignar: local p = self.entity.position; p.y = 3; self.entity.position = p.

Physics

Physics.raycast(origen, dirección, distancia) lanza un rayo (distancia por defecto: 1000 m). Devuelve nil o una tabla con entity, point, normal y distance. 

-- Suelo bajo los pies (el centro está a 1 m del suelo)
local pies = self.entity.position + Vec3.down * 1.02
local hit = Physics.raycast(pies, Vec3.down, 0.15)
local enSuelo = hit ~= nil
Un rayo que empieza dentro de un collider lo detecta a distancia 0. Para no chocar con tu propio cuerpo, lanza el rayo desde fuera de él (por ejemplo, justo debajo de los pies).

Navegación (NavMesh)

Como en Unreal: crea un Volumen de NavMesh (Crear > Navegación) y dentro se genera sola la malla de navegación a partir de la geometría de colisión. Se ve en verde en la escena (tecla P) y se actualiza en tiempo real al mover, crear o borrar colliders. Lo que tenga que moverse lleva el componente NavAgent (Agente de navegación).

Agente (Entity)

:moveTo(destino)Camina hasta el punto por la malla, esquivando obstáculos y a otros agentes. Devuelve false si el destino no está en la malla.
:stopMoving()Se para.
isMovingSi va hacia un destino (pasa a false al llegar).
remainingDistanceMetros que le quedan por el camino.
navVelocitySu velocidad actual (Vec3).

Sin Rigidbody se mueve por su Transform, pegado a la malla. Con un Rigidbody dinámico se mueve por velocidad (la física sigue actuando). La velocidad, la aceleración, el radio y el giro se ajustan en el Inspector.

Navigation

Navigation.findPath(desde, hasta)Lista de Vec3 con los puntos de giro del camino, o nil.
Navigation.projectPoint(punto, radio)El punto de la malla más cercano, o nil.
Navigation.randomPoint(centro, radio)Un punto al azar de la malla dentro del radio, o nil.
Navigation.raycast(desde, hasta)Devuelve llega, punto: si la línea recta por la malla llega sin salirse, y dónde choca si no.
Navigation.isReady()Si ya hay malla.
La malla sale de los colliders (caja, esfera, cápsula, malla y plano) y de los terrenos con colisión, no de lo que se dibuja. No cuentan los triggers, los Rigidbody dinámicos ni los propios agentes. Un NavModifier bloquea una zona o la encarece (los caminos la rodean si pueden).

Audio

Audio.playOneShot(clip, posición, volumen) reproduce un sonido una vez. El clip es una ruta dentro de Assets. Con posición suena en 3D; con nil suena en 2D. Para sonidos continuos usa un AudioSource y entity:playSound().

Interfaz (UI)

Los controles de interfaz llaman a métodos de un script. En el Inspector de un UIButton, UISlider, UIToggle o UIInputField elige la entidad destino (vacío = la misma) y escribe el nombre del método.

ControlEventoFirma del método
UIButtonAl hacer clicfunction X:OnJugar(boton)
UISliderAl cambiarfunction X:OnVolumen(valor)
UIToggleAl cambiarfunction X:OnCasilla(activa)
UIInputFieldAl cambiar / al pulsar Enterfunction X:OnEscribe(texto)

Prefs y Game

Prefs guarda números y textos que sobreviven al cambiar de escena y entre partidas (como el PlayerPrefs de Unity). 

Prefs.setInt("nivel", 3)
Prefs.setFloat("volumen", 0.8)
Prefs.setString("jugador", "Ana")

local nivel = Prefs.getInt("nivel", 1)       -- segundo argumento: valor por defecto
if Prefs.hasKey("jugador") then Debug.log(Prefs.getString("jugador")) end
Prefs.deleteKey("nivel")
Prefs.deleteAll()

Game.quit()   -- cierra el juego (en el editor, sale de Play)

Debug y Mathf

Debug.log(...), Debug.warn(...) y Debug.error(...) escriben en la consola del editor (aceptan varios valores, como print).

Mathf.pi, Mathf.deg2rad, Mathf.rad2degConstantes.
Mathf.lerp(a, b, t)Interpolación.
Mathf.clamp(v, min, max), Mathf.clamp01(v)Limitar un valor.
Mathf.smoothstep(a, b, v)Transición suave de 0 a 1.
Mathf.moveTowards(actual, objetivo, paso)Acerca un valor sin pasarse.
Mathf.random(min, max)Número aleatorio.

También están disponibles las librerías estándar de Lua math, string, table, utf8 y coroutine.

Ejemplos

Scripts completos listos para copiar a Assets/Scripts/.

Girar un objeto

Aspas de molino, monedas, plataformas… El eje y la velocidad se ajustan en el Inspector.

Girar.lua

local Girar = {
    properties = {
        eje = Vec3(0, 1, 0),   -- eje local
        velocidad = 90.0,      -- grados por segundo
    }
}

function Girar:Update(dt)
    self.entity:rotate(self.eje * (self.velocidad * dt))
end

return Girar

Cámara que sigue al jugador

Se ejecuta en LateUpdate para moverse después de que el jugador ya se movió en su Update.

CamaraSeguir.lua

local CamaraSeguir = {
    properties = {
        objetivo = "Jugador",
        distancia = Vec3(0, 4, 8),  -- detrás y por encima
        suavizado = 6.0,
    }
}

function CamaraSeguir:Start()
    self.target = Scene.find(self.objetivo)
    if not self.target then Debug.warn("No hay ninguna entidad llamada", self.objetivo) end
end

function CamaraSeguir:LateUpdate(dt)
    if not (self.target and self.target:valid()) then return end
    local destino = self.target.position + self.distancia
    local t = Mathf.clamp01(self.suavizado * dt)
    self.entity.position = self.entity.position:lerp(destino, t)
    self.entity:lookAt(self.target.position + Vec3(0, 1, 0))
end

return CamaraSeguir

Jugador con física

Movimiento con WASD y salto con Espacio sobre un Rigidbody con CapsuleCollider. Detecta el suelo con un raycast y fija la velocidad horizontal para que el control sea preciso.

Jugador.lua

local Jugador = {
    properties = {
        velocidad = 6.0,
        correr = 1.6,        -- multiplicador con Shift
        salto = 5.5,         -- m/s hacia arriba
        altura = 1.0,        -- del centro a los pies
    }
}

function Jugador:enSuelo()
    -- El rayo empieza justo fuera de la cápsula para no detectarla
    local pies = self.entity.position + Vec3.down * (self.altura + 0.02)
    return Physics.raycast(pies, Vec3.down, 0.15) ~= nil
end

function Jugador:Update(dt)
    -- Dirección de entrada en el plano (W = hacia -Z, el "forward" del motor)
    local entrada = Vec3(Input.getAxis("Horizontal"), 0, -Input.getAxis("Vertical"))
    if entrada:length() > 1 then entrada = entrada:normalized() end

    local rapidez = self.velocidad
    if Input.getKey("shift") then rapidez = rapidez * self.correr end

    local v = self.entity.velocity
    v.x = entrada.x * rapidez
    v.z = entrada.z * rapidez

    if Input.getKeyDown("space") and self:enSuelo() then
        v.y = self.salto
        Audio.playOneShot("Audio/salto.wav")
    end
    self.entity.velocity = v

    -- Mirar hacia donde camina
    if entrada:length() > 0.1 then
        self.entity:lookAt(self.entity.position + entrada)
    end
end

return Jugador

Disparo con raycast

Al hacer clic, lanza un rayo desde la cámara hacia delante y empuja lo que toque.

Disparo.lua

local Disparo = {
    properties = {
        alcance = 100.0,
        fuerza = 12.0,
        cadencia = 0.15,   -- segundos entre disparos
    }
}

function Disparo:Start()
    self.espera = 0
end

function Disparo:Update(dt)
    self.espera = self.espera - dt
    if not Input.getMouseButton(0) or self.espera > 0 then return end
    self.espera = self.cadencia

    local origen = self.entity.position
    local dir = self.entity.forward
    Audio.playOneShot("Audio/disparo.wav", origen, 0.7)

    local hit = Physics.raycast(origen, dir, self.alcance)
    if hit then
        Debug.log("Impacto en", hit.entity.name, "a", string.format("%.1f m", hit.distance))
        if hit.entity:hasComponent("Rigidbody") then
            hit.entity:addForce(dir * self.fuerza, "impulse")
        end
        local objetivo = hit.entity:getScript()
        if objetivo and objetivo.Dano then objetivo:Dano(25) end
    end
end

return Disparo

Monedas y puntuación

Cada moneda tiene un SphereCollider marcado como trigger y la etiqueta Moneda. El marcador es una entidad con un UIText llamada Marcador.

Moneda.lua

local Moneda = { properties = { valor = 1 } }

function Moneda:Start()
    self.base = self.entity.position
end

function Moneda:Update(dt)
    -- Flota y gira
    self.entity:rotate(Vec3(0, 180 * dt, 0))
    self.entity.position = self.base + Vec3(0, math.sin(Time.time * 3) * 0.15, 0)
end

function Moneda:OnTriggerEnter(other)
    if other.name ~= "Jugador" then return end
    local marcador = Scene.find("Marcador")
    if marcador then marcador:getScript():Sumar(self.valor) end
    Audio.playOneShot("Audio/moneda.wav", self.entity.position)
    self.entity:destroy()
end

return Moneda

Marcador.lua

local Marcador = { properties = {} }

function Marcador:Start()
    self.puntos = 0
    self.total = #Scene.findAllWithTag("Moneda")
    self:pintar()
end

function Marcador:pintar()
    self.entity.text = string.format("Monedas: %d / %d", self.puntos, self.total)
end

function Marcador:Sumar(n)
    self.puntos = self.puntos + n
    self:pintar()
    if self.puntos >= self.total then
        self.entity.color = Vec3(1, 0.85, 0.2)
        Prefs.setInt("record", math.max(Prefs.getInt("record", 0), self.puntos))
        Scene.load("Victoria")
    end
end

return Marcador

Generador de enemigos

Usa una entidad desactivada como plantilla (un "prefab" dentro de la escena) y la copia con Scene.instantiate cada cierto tiempo en un punto aleatorio.

Generador.lua

local Generador = {
    properties = {
        plantilla = "EnemigoPlantilla",
        intervalo = 2.0,
        radio = 10.0,
        maximo = 12,
    }
}

function Generador:Start()
    self.molde = Scene.find(self.plantilla)
    self.reloj = 0
end

function Generador:Update(dt)
    if not self.molde then return end
    self.reloj = self.reloj + dt
    if self.reloj < self.intervalo then return end
    self.reloj = 0

    if #Scene.findAllWithTag("Enemigo") >= self.maximo then return end

    local angulo = Mathf.random(0, 2 * Mathf.pi)
    local punto = self.entity.position + Vec3(math.cos(angulo), 0, math.sin(angulo)) * self.radio
    local enemigo = Scene.instantiate(self.molde, punto)
    enemigo.name = "Enemigo"
    enemigo.tag = "Enemigo"
    enemigo.active = true
end

return Generador

Enemigo.lua

local Enemigo = { properties = { velocidad = 2.5, vida = 50 } }

function Enemigo:Start()
    self.jugador = Scene.find("Jugador")
end

function Enemigo:Update(dt)
    if not self.jugador then return end
    local hacia = self.jugador.position - self.entity.position
    hacia.y = 0
    if hacia:length() > 1.2 then
        self.entity:translate(hacia:normalized() * self.velocidad * dt)
        self.entity:lookAt(self.jugador.position)
    end
end

function Enemigo:Dano(cantidad)   -- lo llama Disparo.lua
    self.vida = self.vida - cantidad
    if self.vida <= 0 then
        Audio.playOneShot("Audio/explosion.wav", self.entity.position)
        self.entity:destroy()
    end
end

return Enemigo

Conducir un vehículo

En una entidad con Rigidbody, Vehicle y ruedas con WheelCollider. Muestra la velocidad en un UIText llamado Velocimetro.

Coche.lua

local Coche = { properties = { respuesta = 3.0 } }

function Coche:Start()
    self.giro = 0
    self.hud = Scene.find("Velocimetro")
end

function Coche:Update(dt)
    local acelerador = Input.getAxis("Vertical")
    local objetivo = Input.getAxis("Horizontal")
    -- Volante progresivo: no gira de golpe
    self.giro = Mathf.moveTowards(self.giro, objetivo, self.respuesta * dt)

    local freno = Input.getKey("s") and self.entity.speed > 5 and 1 or 0
    local mano = Input.getKey("space") and 1 or 0
    self.entity:setVehicleInput(acelerador, self.giro, freno, mano)

    if self.hud then
        self.hud.text = string.format("%3d km/h   %4d rpm   marcha %d",
            math.floor(self.entity.speed), math.floor(self.entity.rpm), self.entity.gear)
    end

    if Input.getKeyDown("r") then   -- enderezar
        self.entity.rotation = Vec3(0, self.entity.rotation.y, 0)
        self.entity.position = self.entity.position + Vec3(0, 1, 0)
    end
end

return Coche

Menú, opciones y récord

El método OnJugar se conecta al UIButton "Jugar", OnVolumen a un UISlider y OnSalir al botón "Salir". El volumen y el récord se guardan con Prefs.

Menu.lua

local Menu = { properties = { primerNivel = "Nivel1" } }

function Menu:Start()
    local record = Prefs.getInt("record", 0)
    local texto = Scene.find("Menu_Record")
    if texto then
        texto.text = record > 0 and ("Récord: " .. record) or "¡Juega tu primera partida!"
    end
    local slider = Scene.find("Menu_Volumen")
    if slider then slider.value = Prefs.getFloat("volumen", 1.0) end
end

function Menu:OnJugar(boton)
    Audio.playOneShot("Audio/click.wav")
    Scene.load(self.primerNivel)
end

function Menu:OnVolumen(valor)
    Prefs.setFloat("volumen", valor)
end

function Menu:OnSalir(boton)
    Game.quit()
end

function Menu:Update(dt)
    if Input.getKeyDown("enter") then self:OnJugar(nil) end
end

return Menu

Animación de un personaje

Alimenta los parámetros del controlador de animación a partir de la velocidad del Rigidbody.

AnimarPersonaje.lua

local AnimarPersonaje = { properties = {} }

function AnimarPersonaje:Update(dt)
    local v = self.entity.velocity
    local plano = Vec3(v.x, 0, v.z):length()
    self.entity:setAnimatorFloat("Velocidad", plano)
    self.entity:setAnimatorBool("EnAire", math.abs(v.y) > 0.5)
    if Input.getKeyDown("e") then
        self.entity:setAnimatorTrigger("Saludar")
    end
end

return AnimarPersonaje

Sin controlador, también puedes reproducir un clip directamente: self.entity:playAnimation("Correr", true).

Scripts que se hablan

entity:getScript() devuelve la instancia del script de otra entidad: puedes leer sus datos y llamar a sus métodos. Así, un gestor de nivel puede coordinar a los demás.

Puerta.lua

local Puerta = { properties = { altura = 3.0, velocidad = 2.0 } }

function Puerta:Start()
    self.cerrada = self.entity.position
    self.abierta = self.cerrada + Vec3(0, self.altura, 0)
    self.abriendo = false
end

function Puerta:Abrir()
    if not self.abriendo then Audio.playOneShot("Audio/puerta.wav", self.cerrada) end
    self.abriendo = true
end

function Puerta:Update(dt)
    local destino = self.abriendo and self.abierta or self.cerrada
    local p = self.entity.position
    p.y = Mathf.moveTowards(p.y, destino.y, self.velocidad * dt)
    self.entity.position = p
end

return Puerta

Palanca.lua (en un trigger junto a la puerta)

local Palanca = { properties = { puerta = "Puerta" } }

function Palanca:OnTriggerStay(other)

IA: patrullar y perseguir

Un guardia con NavAgent que patrulla por puntos al azar y persigue al jugador cuando lo ve (el raycast de la malla comprueba que no haya una pared en medio). Si lo pierde, vuelve a patrullar.

Guardia.lua

local Guardia = {
    properties = {
        radioPatrulla = 12.0,
        vision = 10.0,
    }
}

function Guardia:Start()
    self.casa = self.entity.position
    self.jugador = Scene.find("Jugador")
    self.estado = "patrulla"
    self.espera = 0
end

function Guardia:veAlJugador()
    if not self.jugador then return false end
    if self.entity:distanceTo(self.jugador) > self.vision then return false end
    local libre = Navigation.raycast(self.entity.position, self.jugador.position)
    return libre
end

function Guardia:Update(dt)
    if self:veAlJugador() then
        self.estado = "persigue"
        self.entity:moveTo(self.jugador.position)
        return
    end

    if self.estado == "persigue" then
        -- Lo perdio: va al ultimo sitio donde lo vio y luego patrulla.
        if not self.entity.isMoving then self.estado = "patrulla" end
        return
    end

    -- Patrulla: un punto al azar alrededor de casa, espera y otro.
    if not self.entity.isMoving then
        self.espera = self.espera - dt
        if self.espera <= 0 then
            local punto = Navigation.randomPoint(self.casa, self.radioPatrulla)
            if punto then self.entity:moveTo(punto) end
            self.espera = Mathf.random(1, 3)
        end
    end
end

return Guardia
